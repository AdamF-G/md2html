# Mounts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A site's shell says where each source appears in the site with `[[mount]]` markers, and a build adds more with `--mount`. A mounted site builds every Markdown file its mounts hold, at its site path, and nothing else.

**Architecture:** `ReadMounts` reads the shell's `[[mount]]` markers and any `--mount` values into checked `Mount`s. With `CrawlOptions.Mounts` set, `Crawl` hands off to `crawlMounts`: each `.md` under a mount belongs to the deepest mount holding it, so a deeper mount hoists its files out of an enclosing one, and its **site path** (`Doc.SitePath`) decides its output and its place in the tree. The run's base becomes the source root. `siteRules` learns `place` and `owner`, so "in the site" means held by a mount, and a copied file lands at its site path. The site tree is built from site paths for every build, and each mount's `nav-title`, `nav-order`, `nav-sort` and `toc` apply to its node. `[[mount]]` disappears from the shell, warns in a page, `toc="shell"` drops a mounted page's own contents list, `toc: none` reaches the shell, and `@file#key` stays inside the source root.

**Tech Stack:** Go 1.26; `golang.org/x/net/html`; the existing marker parser (`findMarkers`, `markerAttrRe`).

**Spec:** `docs/specs/2026-10-16-mounts-design.md` §3 (Mounts), §4's mount-only rules (the source root's default from the mounts, the read bound), §6 (`toc="shell"`, `toc: none` under a shell), and the order-by-links note's mount attribute (`docs/specs/2026-10-16-order-by-links-design.md` §1). §5's directory pages (a written page for a segment no mount provides, `README.md` as a directory's page, `title-case:`, a mount's `title`) are the next plan's: here a directory with no `index.md` stays a label, with a warning, as today, and `title` is read and kept for it.

## Global Constraints

- Work on `main` in the user's checkout. Conventional prefixes. Commit bodies wrapped at 72 columns, starting from what was wrong before. No attribution trailer. Nothing is pushed.
- **A build without mounts is unchanged**, byte for byte: every existing test passes untouched, except where a task says it edits one.
- `[[mount]]` attributes, exactly: `source` (required; a directory or `.md` file, relative to the shell for a marker and to the working directory for `--mount`, or absolute), `path` (slash path, no leading or trailing `/`, no `.` or `..`; absent is the root; a trailing `.md` on a file mount's path is dropped), `exclude` (comma-separated, relative to the mount's source), `nav-title`, `nav-order` (a whole number), `nav-sort` (`links` or `label`), `toc` (`page` or `shell`), `title`. Any other attribute is an error.
- Exactly one mount is the root. One source mounted twice is an error. Two directory mounts at one path may set `nav-title`, `nav-order`, `nav-sort`, `toc` or `title` only to the same value. A missing source, a file source that is not Markdown, and a source `--exclude` names are errors. Every error names where the mount was declared.
- A file belongs to the deepest mount holding it: a file mount of exactly that file, else the directory mount whose source holds it most deeply.
- With mounts: entries, `--depth` and `--link-depth` are refused, `-o` is required, no link is followed, and nothing is built that no mount holds. `--exclude` applies to every mount, relative to the source root.
- The source root's default is the deepest directory holding the shell and every mount's source; `source-root:` and `--source-root` still win, and a default at the filesystem's root is still refused.
- In a mounted site, a chart's data and a front matter `@file#key` reference are read only from inside the source root; a reference outside it warns and is empty. A build without mounts reads as today.
- Every warning md2html raises has an entry in `docs/guide/warnings.md` (`TestEveryWarningIsInTheGuide`).
- Run `gofmt -l .` (empty), `go vet ./...` and `go test ./...` before every commit.

## Review Focus

1. **A mount whose source holds the shell** (a root mount of `docs/` with the shell in `docs/site/`): the shell must not become a page, and its directory must not become an empty section. Pinned in Task 3.
2. **A symlink inside a mount**: a symlinked `.md` that resolves outside every mount must not be built, and one that resolves into another mount must be built once, at the other mount's site path. Pinned in Task 3.
3. **A link from a file mount's page to a sibling file the mount does not hold** (README's `./LICENSE`): it is outside the site, so it follows `unmounted:`, not a copy. Pinned in Task 3.
4. **Two mounts sharing a directory**, a root mount's `guide/` and a mount at `guide`: their pages merge into one directory node with one set of settings. Pinned in Task 4.
5. **`--mount` with a relative source run from another directory**: it resolves from the working directory, not the shell's. Pinned in Task 7.

package md2html

import (
	"fmt"
	"os"
	"path"
	"path/filepath"
	"regexp"
	"strconv"
	"strings"
)

// Mount places a source in a site: a directory, whose Markdown files become
// pages below Path, or one Markdown file, which becomes the page at Path. A
// site's shell declares its mounts with [[mount]] markers, and a build adds
// more with --mount; see ReadMounts.
type Mount struct {
	// Path is where the source appears in the site, a slash path with no
	// leading or trailing slash; "" is the site's root.
	Path string
	// Source is the directory or .md file, absolute and symlink-resolved.
	Source string
	// IsDir reports whether Source is a directory.
	IsDir bool
	// Exclude lists directory prefixes and name globs, as
	// CrawlOptions.Exclude, relative to Source. A directory mount's only.
	Exclude []string
	// NavTitle, when set, is the mount's label in the site's tree.
	NavTitle string
	// NavOrder, when HasNavOrder, is the mount's place among its siblings.
	NavOrder    int
	HasNavOrder bool
	// NavSort, "links" or "label" when set, orders a directory mount's
	// children, and those of every directory below it that sets none.
	NavSort string
	// TOC is "shell" when the shell's [[toc]] is the mounted pages' only
	// contents list; "" or "page" leaves their own alone.
	TOC string
	// Title is the title of the mount's directory page when md2html writes
	// one.
	Title string
	// From says where the mount was declared, for messages.
	From string
}

// mountAttrsRe matches a --mount value: a marker's attributes and nothing
// else.
var mountAttrsRe = regexp.MustCompile(`^(?:\s*[a-z][a-z-]*="[^"]*")*\s*$`)

// ReadMounts returns the mounts a site declares: the [[mount]] markers in
// the shell at shell, whose sources are relative to the shell, then each
// --mount value in flags, written as a marker's attributes, whose sources
// are relative to the working directory. A shell and flags that declare
// none give none, and the site is built from its entries as before. Every
// mount is checked here, so a build with a bad one stops before it starts.
func ReadMounts(shell string, flags []string) ([]Mount, error) {
	shellAbs, err := resolve(shell)
	if err != nil {
		return nil, fmt.Errorf("site shell: %w", err)
	}
	raw, err := os.ReadFile(shellAbs)
	if err != nil {
		return nil, fmt.Errorf("site shell: %w", err)
	}
	_, body, _ := splitFrontMatter(raw)
	root, err := parseDoc(body)
	if err != nil {
		return nil, fmt.Errorf("site shell %s: %w", shell, err)
	}
	var mounts []Mount
	n := 0
	for _, m := range findMarkers(root) {
		if m.name != "mount" {
			continue
		}
		n++
		mt, err := parseMount(m.attrs, filepath.Dir(shellAbs), fmt.Sprintf("%s: [[mount]] %d", shell, n))
		if err != nil {
			return nil, err
		}
		mounts = append(mounts, mt)
	}
	if len(flags) > 0 {
		cwd, err := os.Getwd()
		if err != nil {
			return nil, err
		}
		for i, f := range flags {
			from := fmt.Sprintf("--mount %d", i+1)
			if !mountAttrsRe.MatchString(f) {
				return nil, fmt.Errorf("%s: %q is not key=\"value\" attributes, as a [[mount]] marker's are", from, f)
			}
			attrs := map[string]string{}
			for _, a := range markerAttrRe.FindAllStringSubmatch(f, -1) {
				attrs[a[1]] = a[2]
			}
			mt, err := parseMount(attrs, cwd, from)
			if err != nil {
				return nil, err
			}
			mounts = append(mounts, mt)
		}
	}
	if len(mounts) == 0 {
		return nil, nil
	}
	if err := checkMounts(mounts); err != nil {
		return nil, err
	}
	return mounts, nil
}

// parseMount reads one mount's attributes. dir is what a relative source is
// read from: the shell's directory for a marker, the working directory for
// a flag. from names the mount in messages.
func parseMount(attrs map[string]string, dir, from string) (Mount, error) {
	m := Mount{From: from}
	for k := range attrs {
		switch k {
		case "source", "path", "exclude", "nav-title", "nav-order", "nav-sort", "toc", "title":
		default:
			return m, fmt.Errorf("%s: unknown attribute %q", from, k)
		}
	}
	src := attrs["source"]
	if src == "" {
		return m, fmt.Errorf("%s: needs a source", from)
	}
	p := filepath.FromSlash(src)
	if !filepath.IsAbs(p) {
		p = filepath.Join(dir, p)
	}
	abs, err := resolve(p)
	if err != nil {
		return m, fmt.Errorf("%s: source %s: %w", from, src, err)
	}
	fi, err := os.Stat(abs)
	if err != nil {
		return m, fmt.Errorf("%s: source %s does not exist", from, src)
	}
	m.Source, m.IsDir = abs, fi.IsDir()
	if !m.IsDir && !IsMarkdownPath(abs) {
		return m, fmt.Errorf("%s: source %s is not a directory or a Markdown file", from, src)
	}
	sp := attrs["path"]
	if !m.IsDir {
		sp = strings.TrimSuffix(sp, ".md")
	}
	if sp != "" && (strings.HasPrefix(sp, "/") || strings.HasSuffix(sp, "/") || strings.Contains(sp, `\`) ||
		path.Clean(sp) != sp || sp == "." || sp == ".." || strings.HasPrefix(sp, "../")) {
		return m, fmt.Errorf("%s: path %q is not a site path: names joined by /, with no leading or trailing /, and no . or ..", from, attrs["path"])
	}
	m.Path = sp
	if v := attrs["exclude"]; v != "" {
		for _, e := range strings.Split(v, ",") {
			if e = strings.TrimSpace(e); e != "" {
				m.Exclude = append(m.Exclude, e)
			}
		}
	}
	m.NavTitle, m.Title = attrs["nav-title"], attrs["title"]
	if v, ok := attrs["nav-order"]; ok {
		i, err := strconv.Atoi(v)
		if err != nil {
			return m, fmt.Errorf("%s: nav-order %q is not a whole number", from, v)
		}
		m.NavOrder, m.HasNavOrder = i, true
	}
	switch v := attrs["nav-sort"]; v {
	case "", "links", "label":
		m.NavSort = v
	default:
		return m, fmt.Errorf("%s: nav-sort %q is not links or label", from, v)
	}
	switch v := attrs["toc"]; v {
	case "", "page", "shell":
		m.TOC = v
	default:
		return m, fmt.Errorf("%s: toc %q is not page or shell", from, v)
	}
	if !m.IsDir && (m.NavSort != "" || len(m.Exclude) > 0) {
		return m, fmt.Errorf("%s: nav-sort and exclude apply to a directory mount, and %s is a file", from, src)
	}
	return m, nil
}

// checkMounts checks what no one mount can: one root, no source mounted
// twice, and one value per setting for a directory two mounts share.
func checkMounts(mounts []Mount) error {
	var root *Mount
	bySource := map[string]*Mount{}
	byDir := map[string]*Mount{}
	for i := range mounts {
		m := &mounts[i]
		if m.Path == "" {
			if root != nil {
				return fmt.Errorf("%s and %s both mount the site's root; give one of them a path", root.From, m.From)
			}
			root = m
		}
		if prev := bySource[m.Source]; prev != nil {
			return fmt.Errorf("%s and %s both mount %s", prev.From, m.From, m.Source)
		}
		bySource[m.Source] = m
		if !m.IsDir {
			continue
		}
		prev := byDir[m.Path]
		if prev == nil {
			byDir[m.Path] = m
			continue
		}
		for _, s := range []struct{ name, a, b string }{
			{"nav-title", prev.NavTitle, m.NavTitle},
			{"nav-sort", prev.NavSort, m.NavSort},
			{"toc", prev.TOC, m.TOC},
			{"title", prev.Title, m.Title},
		} {
			if s.a != "" && s.b != "" && s.a != s.b {
				return fmt.Errorf("%s and %s both mount directory %s with different %s: %q and %q",
					prev.From, m.From, displaySitePath(m.Path), s.name, s.a, s.b)
			}
		}
		if prev.HasNavOrder && m.HasNavOrder && prev.NavOrder != m.NavOrder {
			return fmt.Errorf("%s and %s both mount directory %s with different nav-order: %d and %d",
				prev.From, m.From, displaySitePath(m.Path), prev.NavOrder, m.NavOrder)
		}
	}
	if root == nil {
		return fmt.Errorf("no mount is the site's root: give one mount no path")
	}
	return nil
}

// displaySitePath names a site path in a message.
func displaySitePath(p string) string {
	if p == "" {
		return "the site's root"
	}
	return p
}

// owner is the mount holding target: a file mount of exactly target, else
// the directory mount whose source holds it most deeply, so a deeper mount
// takes its files out of an enclosing one. Nil when no mount holds it.
func (r *siteRules) owner(target string) *mountRule {
	var best *mountRule
	for i := range r.mounts {
		mr := &r.mounts[i]
		if !mr.IsDir {
			if mr.Source == target {
				return mr
			}
			continue
		}
		if isUnder(target, mr.Source) && (best == nil || len(mr.Source) > len(best.Source)) {
			best = mr
		}
	}
	return best
}

// place is where target sits in the site, as a slash path from the site's
// root, and whether the site holds it at all: under the base without
// mounts, or held by a mount, at the mount's path.
func (r *siteRules) place(target string) (string, bool) {
	if r.mounts == nil {
		return relUnder(r.base, target)
	}
	mr := r.owner(target)
	if mr == nil {
		return "", false
	}
	if !mr.IsDir {
		if mr.Path == "" {
			return "index" + path.Ext(target), true
		}
		return mr.Path + path.Ext(target), true
	}
	rel, ok := relUnder(mr.Source, target)
	if !ok {
		return "", false
	}
	return path.Join(mr.Path, rel), true
}

func (r *siteRules) excludedAt(target string) bool {
	if r.excluded.match(target) {

	mr := r.owner(target)

// crawlMounts is Crawl for a site its mounts describe. Each Markdown file a
// mount holds, and no deeper mount holds instead, is a page at its site
// path; a file excluded by --exclude, relative to the source root, or by its
// mount's own excludes, is not. No link is followed: what the mounts hold is
// the whole site.
func crawlMounts(opt CrawlOptions) (*CrawlResult, error) {
	if len(opt.Entries) > 0 {
		return nil, fmt.Errorf("the site's mounts say what it holds; give no entry points beside them")
	}
	if opt.SiteShell == "" || opt.OutDir == "" {
		return nil, fmt.Errorf("mounts need a site shell and an output directory")
	}
	out, err := filepath.Abs(opt.OutDir)
	if err != nil {
		return nil, err
	}
	opt.OutDir = out
	rules, err := newSiteRules(opt, "", exclusions{})
	if err != nil {
		return nil, err
	}
	base := rules.sourceRoot
	excluded, excludeWarnings := resolveExcludes(opt.Exclude, base)
	rules.excluded = excluded
	res := &CrawlResult{Base: base, Warnings: excludeWarnings}
	rules.mounts = make([]mountRule, len(opt.Mounts))
	for i := range opt.Mounts {
		m := &opt.Mounts[i]
		if excluded.match(m.Source) {
			return nil, fmt.Errorf("%s: source %s is excluded by --exclude", m.From, m.Source)
		}
		mr := mountRule{Mount: m, excluded: exclusions{base: m.Source}}
		if m.IsDir {
			var w []Warning
			mr.excluded, w = resolveExcludes(m.Exclude, m.Source)
			res.Warnings = append(res.Warnings, w...)
		}
		rules.mounts[i] = mr
	}

	mountOf := map[string]*Mount{}
	for i := range rules.mounts {
		mr := &rules.mounts[i]
		cands := []string{mr.Source}
		if mr.IsDir {
			cands = nil
			_ = filepath.WalkDir(mr.Source, func(p string, d os.DirEntry, err error) error {
				if err != nil {
					return nil // unreadable subtree: skip, do not abort
				}
				if p != mr.Source && (excluded.match(p) || mr.excluded.match(p)) {
					if d.IsDir() {
						return filepath.SkipDir
					}
					return nil
				}
				if !d.IsDir() && IsMarkdownPath(p) {
					cands = append(cands, p)
				}
				return nil
			})
		}
		for _, p := range cands {
			real, err := resolve(p)
			if err != nil {
				continue
			}
			if real == rules.shell {
				continue // the shell is the site's template, never a page
			}
			owner := rules.owner(real)
			if owner == nil {
				res.Warnings = append(res.Warnings, Warning{p,
					fmt.Sprintf("not building %s: it is outside the site's root %s", p, base)})
				continue
			}
			if owner != mr || rules.excludedAt(real) {
				continue // a deeper mount holds it, or it is excluded there
			}
			mountOf[real] = owner.Mount
		}
	}

	order := make([]string, 0, len(mountOf))
	for src := range mountOf {
		order = append(order, src)
	}
	sort.Strings(order)
	linksBySrc := map[string][]Link{}
	for _, src := range order {
		d, ok := discover(src, res)
		if !ok {
			continue
		}
		sp, _ := rules.place(src)
		outPath := filepath.Join(out, filepath.FromSlash(strings.TrimSuffix(sp, path.Ext(sp))+".html"))
		res.Docs = append(res.Docs, Doc{Src: src, Out: outPath, SitePath: sp,
			Meta: d.meta, Title: d.title, mount: mountOf[src]})
		linksBySrc[src] = d.links
	}
	if err := checkOutputs(res.Docs); err != nil {
		return nil, err
	}
	res.rules = rules
	if err := buildLinkMaps(res, opt, linksBySrc); err != nil {
		return nil, err
	}
	return res, nil
}

// applyMounts gives each mount's node the mount's settings, over the page's
// own: its label and place among its siblings, and how a directory's
// children are ordered, which reaches every directory below it up to one
// that sets its own, whose setting holds for its subtree.
func (s *Site) applyMounts() {
	for i := range s.crawl.Mounts {
		m := &s.crawl.Mounts[i]
		var n *siteNode
		if m.IsDir {
			n = s.dirs[m.Path]
		} else if m.Path == "" {
			n = s.root
		} else {
			n = s.bySrc[m.Source]
		}
		if n == nil {
			continue
		}
		if m.NavTitle != "" {
			n.label = m.NavTitle
		}
		if m.HasNavOrder {
			n.order, n.hasOrder = m.NavOrder, true
		}
		if m.NavSort == "" {
			continue
		}
		sortAs := ""
		if m.NavSort == "links" {
			sortAs = "links"
		}
		n.navSort, n.navSortSet = sortAs, true
		var below func(d *siteNode)
		below = func(d *siteNode) {
			for _, c := range d.children {
				if !c.isDir {
					continue
				}
				if c.navSortSet {
					continue // the nearest setting wins, for its whole subtree
				}
				c.navSort = sortAs
				below(c)
			}
		}
		below(n)
	}
}

````markdown
## Mounts {#mounts}

A site's files are rarely in one directory. `[[mount]]` markers in the
shell place sources from anywhere in the repository at paths in the
site, so the shell says what the site holds, and the build needs no
entries:

```markdown
---
site: true
---
[[mount source="../index.md"]]

[[mount path="overview" source="../../README.md" nav-order="1"]]

[[mount path="guide" source="../guide" nav-order="2"]]

[[mount path="design-notes" source="../specs" nav-title="Design Notes"]]
```

```bash
md2html --site docs/site/shell.md -o _site
```

| Attribute | Meaning |
|---|---|
| `source` | A directory or a `.md` file, relative to the shell. Required. |
| `path` | Where it appears in the site, such as `guide` or `handbook/changes`. Absent, the mount is the site's root. |
| `exclude` | Comma-separated directories and name globs, as `--exclude`, relative to the source. |
| `nav-title`, `nav-order` | The mount's label and place, over the page's own. |
| `nav-sort` | `links` orders a directory mount's children by its index's links, and every directory below that sets none. |
| `toc` | `shell` drops the mounted pages' own contents lists, so the shell's `[[toc]]` is the only one. |

- A directory mount builds every `.md` below it, at its path under the
  mount's; a file mount builds that one page. Pages are written at their
  site paths, so `docs/guide/sites.md` mounted at `guide` becomes
  `guide/sites.html`.
- One mount has no `path`: the root. A mount inside another's source
  takes its files out of the enclosing one, and two mounts may share a
  directory, with one value for each setting.
- A link between mounted pages reaches the page where it is written. A
  file a mount holds is in the site; anything else is outside it, and
  follows `unmounted:` (see [Links and files](#links-and-files)).
- `--exclude` applies to every mount, relative to the source root, the
  deepest directory holding the shell and the mounts' sources. A mounted
  site reads chart data and `@file#key` references only from inside it.
- With mounts, entries, `--depth` and `--link-depth` are refused, and
  `-o` is required. `--mount 'path="team" source="notes"'` adds a mount
  for one build, its source read from the working directory.
- `[[mount]]` renders nothing; in a page's body it warns. A page with
  `toc: none` gets no contents list from the shell, in any site.
````

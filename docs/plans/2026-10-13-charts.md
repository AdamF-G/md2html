# Build-Time Charts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `vega-lite` fence renders, when md2html builds the page, as static SVG that follows the page's style and theme, with a CSS hover layer and a table view, and no script on the page.

**Architecture:** A new internal package, `internal/charts`, runs vendored Vega and Vega-Lite inside goja (a pure-Go JavaScript engine). It measures text with the style's real font, and post-processes the SVG into tokenised, namespaced markup with a hover layer and a table. md2html's fenced-code renderer dispatches the fence to it. A new `charts` block in a style's manifest supplies the font, metrics proxy and width. Each built-in stylesheet gains chart tokens and the `md2html-chart` rules.

**Tech Stack:** Go 1.26, goja (`github.com/dop251/goja`), Vega 5.30.0 and Vega-Lite 5.21.0 (vendored minified bundles), `github.com/tdewolff/font` (woff2 and sfnt metrics), chromedp in the `e2e` module.

**Spec:** `docs/specs/2026-10-13-charts-design.md` (approved 2026-10-13). Read it before starting; every task argues from it.

## Global Constraints

- Branch: `plugins`. Commit with conventional prefixes (`feat:`, `fix:`, `test:`, `docs:`, `chore:`), matching the log.
- A fix to an earlier task's own work is `git commit --fixup=<that commit>`, not a new `fix:` commit. One `--autosquash` pass happens at the end of the plan, not per task.
- No product or project names from other repositories in code, tests, comments, docs or commit messages. Chart examples use neutral data.
- md2html never fetches at build time: a chart's data `url` with a scheme or host is refused.
- Output gains no script and no new fetch. `mermaid is the only thing a page can fetch` and `a fragment has no script` stay true. A test in Task 13 holds each.
- Classes and ids that md2html writes for charts are prefixed `md2html-`. Chart ids are `md2html-c<N>-<kind><i>`, where N counts charts on the page from 1.
- Option and flag names: `Options.NoCharts` / `--no-charts`, `Options.DataRoot`, `--licenses`.
- Never call `font.ParseFont` from `tdewolff/font`: it prints a deprecation warning to stdout. Use `font.ParseWOFF2`, then `font.ParseSFNT`.
- goja is pinned by `go.mod`'s pseudo-version. Any commit that passes the golden tests will do, whatever its age.
- Every built-in plugin must load without warnings (an existing test enforces this).
- Run `go test ./...` from the repo root before every commit, and `cd e2e && go test -count=1 ./...` for any task that touches markup, CSS or the e2e module. Long runs redirect to a file, for example `go test ./... > /tmp/md2html-test.txt 2>&1`.

## Review Focus

- **Concurrent conversion.** The CLI converts documents in parallel, and a goja runtime is not goroutine-safe. Charts converted at the same time from many goroutines must each render correctly, with no data race. *Pinned by Task 2, Step 6 (`go test -race`).*
- **A runaway spec.** A spec that would run for minutes (a `sequence` of 10⁹ rows) must hit the time budget: one warning, the fence becomes a code block, and the next chart on the page still renders. *Pinned by Task 2, Step 7.*
- **Markup in author text.** `<`, `&` and quotes in labels, tooltips and data values must reach tooltip boxes, `aria-label`s and table cells as text, never as markup. *Pinned by Task 7, Step 6 and Task 9, Step 3.*
- **A stylesheet without chart tokens** (`--css` replacing the default). Charts must still be visible: they render with the `default` style's literal colours instead of `var()`. *Pinned by Task 10, Step 8.*
- **Many charts, and charts inside containers.** Ten charts on a page, charts inside `::: details` and list items, and charts beside `fig` figures must all keep unique ids and working hover. *Pinned by Task 13, Step 5.*

// rendered is what the engine returns for one chart.
type rendered struct {
	SVG      string   `json:"svg"`
	Width    float64  `json:"width"`  // SVG width in px
	Height   float64  `json:"height"`

	Rows     []map[string]any `json:"rows"`   // the main dataset, for the table (Task 9)

```js
// The glue between md2html and Vega. render() is called once per chart and
// resolves to the object Go reads back as `rendered`.
function render(specJSON) {
  var warnings = [];
  var spec = JSON.parse(specJSON);
  var compiled = vegaLite.compile(spec, { logger: { warn: function (m) { warnings.push(String(m)); return this; },
    info: function () { return this; }, debug: function () { return this; }, error: function (m) { throw new Error(String(m)); },
    level: function () { return this; } } }).spec;
  var loader = vega.loader();
  loader.load = function (uri) {
    return new Promise(function (resolve, reject) {
      try { resolve(goLoad(String(uri))); } catch (e) { reject(e); }
    });
  };
  var view = new vega.View(vega.parse(compiled), { renderer: "none", loader: loader });
  view.logger({ warn: function (m) { warnings.push(String(m)); }, info: function () {}, debug: function () {}, error: function (m) { warnings.push(String(m)); } });
  return view.toSVG().then(function (svg) {
    var marks = [];
    (function walk(node, ox, oy) {
      var items = (node && node.items) || [];
      for (var i = 0; i < items.length; i++) {
        var it = items[i], type = it.mark && it.mark.marktype;
        if (it.tooltip != null && it.bounds && (type === "symbol" || type === "rect" || type === "area" || type === "line" || type === "arc")) {
          var tip = it.tooltip;
          var lines = typeof tip === "object" ? Object.keys(tip).map(function (k) { return k + ": " + tip[k]; }) : [String(tip)];
          marks.push({ tooltip: lines, label: it.description == null ? "" : String(it.description),
            X1: ox + it.bounds.x1, Y1: oy + it.bounds.y1, X2: ox + it.bounds.x2, Y2: oy + it.bounds.y2, symbol: type === "symbol" });
        }
        var gx = ox + (type === "group" ? (it.x || 0) : 0), gy = oy + (type === "group" ? (it.y || 0) : 0);
        if (it.items) for (var j = 0; j < it.items.length; j++) walk(it.items[j], gx, gy);
      }
    })(view.scenegraph().root, view.origin()[0], view.origin()[1]);
    var rows = [];
    try { rows = view.data("source_0") || []; } catch (e) { rows = []; }
    var fields = [];
    (function collect(s) {
      if (!s) return;
      var enc = s.encoding || {};
      Object.keys(enc).forEach(function (ch) {
        var defs = Array.isArray(enc[ch]) ? enc[ch] : [enc[ch]];
        defs.forEach(function (d) { if (d && typeof d.field === "string" && fields.indexOf(d.field) < 0) fields.push(d.field); });
      });
      (s.layer || []).forEach(collect);
    })(spec);
    return { svg: svg, width: view.width() + view.origin()[0] * 2, height: view.height() + view.origin()[1] * 2,
      marks: marks, rows: rows.map(function (r) { var o = {}; fields.forEach(function (f) { o[f] = r[f]; }); return o; }),
      fields: fields, warnings: warnings };
  });
}
```

`width` and `height` are corrected from the SVG's own attributes in Go (Step 5), since padding is not always symmetric. The JavaScript values are a fallback.

```go
// Package charts renders Vega-Lite specs to static SVG when md2html builds
// a page, inside an embedded JavaScript engine. Nothing it produces needs a
// script to display.
package charts

import (
	_ "embed"
	"encoding/json"
	"errors"
	"fmt"
	"regexp"
	"strconv"
	"sync"
	"time"

	"github.com/dop251/goja"
)

var (
	//go:embed vendor/vega.min.js
	vegaJS string
	//go:embed vendor/vega-lite.min.js
	vegaLiteJS string
	//go:embed driver.js
	driverJS string
)

// budget is how long one chart may run before it is interrupted. A var so
// a test can shorten it.
var budget = 5 * time.Second

type engine struct {
	vm      *goja.Runtime
	render  goja.Callable
	timers  []*timer
	clock   time.Duration
	measure Measurer
	load    func(string) (string, error)
}

type timer struct {
	fn    goja.Callable
	at    time.Duration
	alive bool
}

var (
	mu  sync.Mutex // goja runtimes are not goroutine-safe; one chart at a time
	cur *engine    // built on first use, rebuilt after an interrupt
)

func newEngine() (*engine, error) {
	e := &engine{vm: goja.New()}
	vm := e.vm
	vm.Set("setTimeout", func(c goja.FunctionCall) goja.Value {
		fn, ok := goja.AssertFunction(c.Argument(0))
		if !ok {
			return goja.Undefined()
		}
		e.timers = append(e.timers, &timer{fn: fn, at: e.clock + time.Duration(c.Argument(1).ToInteger())*time.Millisecond, alive: true})
		return vm.ToValue(len(e.timers) - 1)
	})
	vm.Set("clearTimeout", func(id int) {
		if id >= 0 && id < len(e.timers) {
			e.timers[id].alive = false
		}
	})
	noop := func(...any) {}
	vm.Set("console", map[string]any{"log": noop, "warn": noop, "error": noop, "info": noop, "debug": noop})
	vm.Set("goMeasure", func(s string, size, weight float64) float64 { return e.measure.Width(s, size, weight) })
	vm.Set("goLoad", func(u string) (string, error) {
		if e.load == nil {
			return "", fmt.Errorf("data url %q: charts read no data files here", u)
		}
		return e.load(u)
	})
	prelude := `
		globalThis.structuredClone = function (v) { return v === undefined ? v : JSON.parse(JSON.stringify(v)); };
		// A seeded generator, reset before each chart, so output is byte-identical.
		globalThis.__seed = 1;
		Math.random = function () { __seed = (__seed * 1103515245 + 12345) % 2147483648; return __seed / 2147483648; };`
	for _, s := range []struct{ name, src string }{{"prelude", prelude}, {"vega.min.js", vegaJS}, {"vega-lite.min.js", vegaLiteJS}, {"driver.js", driverJS}} {
		if _, err := vm.RunScript(s.name, s.src); err != nil {
			return nil, fmt.Errorf("charts: load %s: %w", s.name, err)
		}
	}
	if _, err := vm.RunString(`
		vega.textMetrics.width = function (item, text) {
			var size = item.fontSize != null ? +item.fontSize : 11;
			var w = item.fontWeight == null ? 400 : (item.fontWeight === "bold" ? 700 : (+item.fontWeight || 400));
			return goMeasure(String(text == null ? "" : text), size, w);
		};`); err != nil {
		return nil, err
	}
	fn, ok := goja.AssertFunction(vm.Get("render"))
	if !ok {
		return nil, errors.New("charts: driver.js defines no render")
	}
	e.render = fn
	return e, nil
}

// runTimers fires due timers in time order until none remain.
func (e *engine) runTimers() error {
	for {
		var next *timer
		for _, t := range e.timers {
			if t.alive && (next == nil || t.at < next.at) {
				next = t
			}
		}
		if next == nil {
			return nil
		}
		next.alive = false
		e.clock = next.at
		if _, err := next.fn(goja.Undefined()); err != nil {
			return err
		}
	}
}

var svgSize = regexp.MustCompile(`^<svg[^>]* width="([0-9.]+)" height="([0-9.]+)"`)

func renderSpec(specJSON []byte, m Measurer, load func(string) (string, error)) (rendered, error) {
	mu.Lock()
	defer mu.Unlock()
	if cur == nil {
		e, err := newEngine()
		if err != nil {
			return rendered{}, err
		}
		cur = e
	}
	e := cur
	e.measure, e.load, e.timers, e.clock = m, load, nil, 0
	e.vm.Set("__seed", 1)
	interrupted := false
	stop := time.AfterFunc(budget, func() { interrupted = true; e.vm.Interrupt("time budget") })
	defer stop.Stop()
	fail := func(err error) (rendered, error) {
		if interrupted {
			cur = nil // a runtime cut off mid-run is not trusted again
			return rendered{}, fmt.Errorf("chart ran past its %v time budget", budget)
		}
		return rendered{}, err
	}
	pv, err := e.render(goja.Undefined(), e.vm.ToValue(string(specJSON)))
	if err != nil {
		return fail(err)
	}
	if err := e.runTimers(); err != nil {

		return rendered{}, err

		return rendered{}, err

		r.Width, _ = strconv.ParseFloat(m[1], 64)
		r.Height, _ = strconv.ParseFloat(m[2], 64)

package charts

import (
	"bytes"

	"github.com/tdewolff/font"
)

type fontMeasurer struct{ f *font.SFNT }

// NewFontMeasurer reads woff2, TrueType or OpenType bytes. A variable
// font's default instance gives the advances; heavier text is widened by a
// fixed factor per 100 of weight, which kept the spike within 1 px of the
// browser. Applying the wght axis through HVAR is a follow-up.
func NewFontMeasurer(b []byte) (Measurer, error) {
	if bytes.HasPrefix(b, []byte("wOF2")) {
		raw, err := font.ParseWOFF2(b)
		if err != nil {
			return nil, err
		}
		b = raw
	}
	f, err := font.ParseSFNT(b, 0)
	if err != nil {
		return nil, err
	}
	return fontMeasurer{f}, nil
}

func (m fontMeasurer) Width(s string, size, weight float64) float64 {
	var w float64
	var prev uint16
	for i, r := range s {
		g := m.f.GlyphIndex(r)
		if i > 0 {
			w += float64(m.f.Kerning(prev, g))
		}
		w += float64(m.f.GlyphAdvance(g))
		prev = g
	}
	return w * size / float64(m.f.Head.UnitsPerEm) * (1 + (weight-400)/100*0.018)
}

package charts

type systemSans struct{ pad float64 }

// SystemSans measures text set in the reader's system sans, which md2html
// cannot know when it builds the page, using Inter's advances as a proxy
// and widening every width by pad (0.1 is ten percent), so a wider system
// face still fits.
func SystemSans(pad float64) Measurer { return systemSans{pad} }

func (m systemSans) Width(s string, size, weight float64) float64 {
	fallback := float64(systemSansAdvance['n'-0x20])
	var units float64
	for _, r := range s {
		if r >= 0x20 && int(r-0x20) < len(systemSansAdvance) {
			units += float64(systemSansAdvance[r-0x20])
		} else {
			units += fallback
		}
	}
	return units * size / systemSansUPM * (1 + (weight-400)/100*0.018) * (1 + m.pad)
}

package charts

import (
	"fmt"
	"regexp"
	"strings"
)

func placeholder(token string) string {
	for i, t := range Tokens {
		if t == token {
			return fmt.Sprintf("#0a0b%02x", i+1)
		}
	}
	return ""
}

func tokenOfPlaceholder(hex string) (string, bool) {
	for _, t := range Tokens {
		if placeholder(t) == hex {
			return t, true
		}
	}
	return "", false
}

// themeConfig is merged under a spec's own config, so the author's
// explicit choices win.
func themeConfig(fontFamily string) map[string]any {
	p := placeholder
	series := make([]any, 8)
	for i := range series {
		series[i] = p(fmt.Sprintf("series-%d", i+1))
	}
	return map[string]any{
		"background": nil, "font": fontFamily, "view": map[string]any{"stroke": nil},
		"axis": map[string]any{"domainColor": p("chart-axis"), "gridColor": p("chart-grid"), "gridWidth": 1,
			"tickColor": p("chart-axis"), "labelColor": p("muted"), "titleColor": p("muted"),
			"labelFontSize": 12, "titleFontSize": 12, "titleFontWeight": 500},
		"legend": map[string]any{"labelColor": p("fg"), "titleColor": p("muted"), "labelFontSize": 12},
		"title":  map[string]any{"color": p("fg")},
		"text":   map[string]any{"color": p("fg"), "fontSize": 12},
		"mark":   map[string]any{"color": p("series-1")},
		"point":  map[string]any{"size": 100, "strokeWidth": 2, "stroke": p("chart-surface")},
		"bar":    map[string]any{"cornerRadiusEnd": 4, "stroke": p("chart-surface"), "strokeWidth": 2},
		"rule":   map[string]any{"color": p("chart-axis")},
		"line":   map[string]any{"strokeWidth": 2, "strokeCap": "round", "strokeJoin": "round"},
		"range":  map[string]any{"category": series},
	}
}

var placeholderRe = regexp.MustCompile(`#0a0b[0-9a-f]{2}`)

func substituteTokenNames(v any) (any, []string) {
	var warns []string
	var walk func(any) any
	walk = func(v any) any {
		switch x := v.(type) {
		case map[string]any:
			for k, e := range x {
				x[k] = walk(e)
			}
		case []any:
			for i, e := range x {
				x[i] = walk(e)
			}
		case string:
			if name, ok := strings.CutPrefix(x, "token:"); ok {
				if p := placeholder(name); p != "" {
					return p
				}
				warns = append(warns, fmt.Sprintf("chart: %q names no chart token; the tokens are %s", x, strings.Join(Tokens, ", ")))
			} else if placeholderRe.MatchString(strings.ToLower(x)) {
				warns = append(warns, fmt.Sprintf("chart: the colour %s is reserved by md2html for a chart token; it will render as that token", x))
			}
		}
		return v
	}
	return walk(v), warns
}

var colourAttr = regexp.MustCompile(`(fill|stroke)="([^"]*)"`)
var styleDup = regexp.MustCompile(`style="([^"]*)" style="([^"]*)"`)

func tokenize(svg string) (string, bool, error) {
	literal := false
	out := colourAttr.ReplaceAllStringFunc(svg, func(s string) string {
		m := colourAttr.FindStringSubmatch(s)
		v := strings.ToLower(m[2])
		if tok, ok := tokenOfPlaceholder(v); ok {
			return fmt.Sprintf(`style="%s: var(--%s)"`, m[1], tok)
		}
		if v != "none" && v != "transparent" && !strings.HasPrefix(v, "url(") {
			literal = true
		}
		return s
	})
	for styleDup.MatchString(out) {
		out = styleDup.ReplaceAllString(out, `style="$1; $2"`)
	}
	if left := placeholderRe.FindString(out); left != "" {
		return "", false, fmt.Errorf("chart: placeholder %s survived the rewrite", left)
	}
	return out, literal, nil
}

var themeBlock = regexp.MustCompile(`:root\[data-theme="(light|dark)"\]\s*\{([^}]*)\}`)
var declRe = regexp.MustCompile(`--([a-z0-9-]+)\s*:\s*([^;]+);`)

func TokenValues(css string) (light, dark map[string]string, ok bool) {
	light, dark = map[string]string{}, map[string]string{}
	want := map[string]bool{}
	for _, t := range Tokens {
		want[t] = true
	}
	for _, b := range themeBlock.FindAllStringSubmatch(css, -1) {
		dst := light
		if b[1] == "dark" {
			dst = dark
		}
		for _, d := range declRe.FindAllStringSubmatch(b[2], -1) {
			if want[d[1]] {
				dst[d[1]] = strings.TrimSpace(d[2]) // later blocks win, as the cascade does
				ok = true
			}
		}
	}
	return light, dark, ok
}

func withColours(svg string, values map[string]string) string {
	return placeholderRe.ReplaceAllStringFunc(svg, func(p string) string {
		if t, ok := tokenOfPlaceholder(p); ok {
			if v, ok := values[t]; ok {
				return v
			}
		}
		return p
	})
}

		if err != nil || p.Scheme != "" || p.Host != "" || strings.HasPrefix(u, "//") {
			return refuse("md2html reads only files beside the page, never the network")
		}
		if filepath.IsAbs(p.Path) {
			return refuse("an absolute path is outside the pages")
		}
		target := filepath.Join(pageDir, filepath.FromSlash(p.Path))
		real, err := filepath.EvalSymlinks(target)
		if err != nil {
			return refuse(err.Error())
		}
		rootReal, err := filepath.EvalSymlinks(root)
		if err != nil {
			return refuse(err.Error())
		}
		if rel, err := filepath.Rel(rootReal, real); err != nil || rel == ".." || strings.HasPrefix(rel, ".."+string(filepath.Separator)) {
			return refuse("it is outside " + root)
		}
		b, err := os.ReadFile(real)
		if err != nil {
			return refuse(err.Error())
		}
		return string(b), nil
	}
}

// inside is the ray-casting point-in-polygon test.
func inside(poly [][2]float64, p [2]float64) bool {
	in := false
	for i, j := 0, len(poly)-1; i < len(poly); j, i = i, i+1 {
		a, b := poly[i], poly[j]
		if (a[1] > p[1]) != (b[1] > p[1]) && p[0] < (b[0]-a[0])*(p[1]-a[1])/(b[1]-a[1])+a[0] {
			in = !in
		}
	}
	return in
}

// hover moves the real pointer to the centre of the element sel names and
// returns the opacity of the element want names.
func hover(t *testing.T, ctx context.Context, sel, want string) string {
	t.Helper()
	var x, y float64
	var op string
	if err := chromedp.Run(ctx,
		chromedp.Evaluate(fmt.Sprintf(`(() => { const r = document.querySelector(%q).getBoundingClientRect(); return r.x + r.width / 2; })()`, sel), &x),
		chromedp.Evaluate(fmt.Sprintf(`(() => { const r = document.querySelector(%q).getBoundingClientRect(); return r.y + r.height / 2; })()`, sel), &y),
		chromedp.ActionFunc(func(ctx context.Context) error { return input.DispatchMouseEvent(input.MouseMoved, x, y).Do(ctx) }),
		chromedp.Sleep(150*time.Millisecond),
		chromedp.Evaluate(fmt.Sprintf(`getComputedStyle(document.querySelector(%q)).opacity`, want), &op),
	); err != nil {
		t.Fatal(err)
	}
	return op
}
```

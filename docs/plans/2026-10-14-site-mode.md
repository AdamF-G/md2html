# Site Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `md2html --site shell.md ./docs -o site` wraps every page in an ordinary Markdown shell page whose markers expand into the site's navigation, lists and search, with a tree derived from the pages and no config file.

**Architecture:** The crawl already sees every document, so it now keeps each one's front matter and title. `BuildSite` turns a crawl plus a shell into a `Site` — the tree, the shell's parsed source, and a concurrency-safe search index — which `Convert` receives through `Options.Site`. Convert renders the page as today, then parses the shell, rewrites the shell's links for that page, expands its markers against the page's place in the tree, and moves the page body into `[[content]]`. Markers are standalone paragraphs like `[[toc]]`; `[[list]]` and `[[subdirs]]` work on any page, the navigation markers only under a shell.

**Tech Stack:** Go 1.26 (module `github.com/AdamF-G/md2html`), goldmark and `golang.org/x/net/html` as already used; `encoding/json` from the standard library for the index. The browser suite (`e2e/`, chromedp) for the two scripts.

**Spec:** `docs/specs/2026-10-14-site-mode-design.md`

## Global Constraints

- No new dependencies in the root module; the e2e module gains no new dependency either.
- A run without `--site`, on pages without the new markers, produces byte-identical output to today, stylesheet included (the markers' base rules are md2html's own `site.css`, added only to a page that carries marker output): every existing test passes unchanged, except `page_test.go`'s `renderPage` calls, which gain the two new arguments.
- New classes and ids are prefixed `md2html-`. New front matter keys: `site`, `shell`, `nav`, `nav-order`, `nav-title`, `search-facets`. New markers: `[[content]]`, `[[pages]]`, `[[breadcrumb]]`, `[[prev-next]]`, `[[search]]`, `[[list]]`, `[[subdirs]]`.
- Front matter stays flat; the only new value form is `@path#key`.
- Template expansion (`{item}`, `{target}`, `{name}`) happens in marker attributes only, never in other text.
- Output is deterministic: the same inputs give the same bytes, including the search index under parallel conversion.
- Every new warning is a sentence that names the thing and what md2html did instead, in the style of the existing ones, and is quoted in `docs/authoring.md`'s Warnings section (Task 10), which `TestGuideWarningsExistInTheCode` checks.
- Commits use conventional prefixes, carry no Co-Authored-By or other attribution trailer, and are not pushed.
- Messages, docs and tests name no product or project from other repositories.
- Run `go vet ./...` and `go test ./...` at the repo root before each commit; Task 9 also runs `just e2e`.

## Review Focus

1. **A URL inside a marker's attributes** (`[[subdirs path="/srv/v" link="https://docs.example.com/{item}/"]]`): GFM turns the URL into an `<a>`, so the paragraph is no longer one text node and a `[[toc]]`-style check misses the marker silently. Pinned by `TestFindMarkersSeesThroughAutolinks` (Task 2) and `TestSubdirsWithAnAbsoluteLink` (Task 3).
2. **A page two directories deep**: every generated href — shell links, `[[pages]]`, breadcrumb, prev/next, the search index path — must be relative to that page, not to the shell or the root. Pinned by `TestSiteWrapsEachPage` (Task 5), `TestPagesMarkersFromANestedPage` (Task 6) and `TestSearchBoxPointsAtTheIndex` (Task 7).
3. **A shell outside the entry points and outside the base**, as a publish job keeps one: its links still resolve and it is never written. Pinned by `TestSiteWrapsEachPage` (the fixture's shell lives in `shell/`, outside `docs/`).
4. **Parallel conversion** records index entries in arbitrary order; the index must still be byte-identical across runs. Pinned by `TestSearchIndexIsSortedAndStable` (Task 7), run under `-race`.
5. **A site opened from disk** (`file://`): browsers block `fetch` there, so search must load its index with a script tag. Pinned by `TestBrowserSearchFromDisk` (Task 9).
6. **One document, two id namespaces**: the shell's transforms run on the shell alone, so a shell heading and a page heading can both get `part-one`. The page's id wins; the shell's is renumbered with its own links, but the shell's contents list must still point at the page. Pinned by `TestSiteShellIDsGiveWayToThePage` (Task 5).
7. **An `@` value nothing reads**: `author: @someone` in a build without markers must neither warn nor change. References resolve only in keys a marker or facet reads. Pinned by `TestConvertLeavesUnreadReferencesAlone` (Task 2) and `TestListResolvesTheKeysItReads` (Task 3).
8. **Where `<main>` is**: under a shell, `[[content]]` is the page's only `<main>` and the shell sits in `<body>` around it, so the reading column's width applies to the page alone. Pinned by `TestSiteWrapsEachPage` (Task 5).

```go
// linkMapFor computes the replacement for each of links, as written in a
// document whose output is fromOut. Document links resolve to other emitted
// documents; asset links point back at the original file, since assets are
// never copied. A site uses it to rewrite its shell's links once per page.
func linkMapFor(links []Link, fromOut string, outBySrc map[string]string, opt CrawlOptions) map[string]string {
	m := map[string]string{}
	outDir := filepath.Dir(fromOut)
	for _, l := range links {
		switch l.Kind {
		case LinkDoc:
			if opt.NoMdLinks {
				continue
			}
			target, err := resolve(l.Abs)
			if err != nil {
				continue
			}
			targetOut, ok := outBySrc[target]
			if !ok {
				continue // not emitted: leave the link as written
			}
			rel, err := filepath.Rel(outDir, targetOut)
			if err != nil {
				continue
			}
			m[l.Href] = encodePath(filepath.ToSlash(rel)) + fragmentOf(l.Href)
		case LinkAsset:
			if opt.NoAssets || opt.OutDir == "" {
				continue
			}
			if _, err := os.Stat(l.Abs); err != nil {
				continue // missing asset: Crawl already warned; leave link as written
			}
			rel, err := filepath.Rel(outDir, l.Abs)
			if err != nil {
				continue
			}
			m[l.Href] = encodePath(filepath.ToSlash(rel))
		}
	}
	return m
}
```

and make `buildLinkMaps`'s loop body `d.LinkMap = linkMapFor(linksBySrc[d.Src], d.Out, outBySrc, opt)`, keeping its comments on why assets point back out.

```go
package md2html

import (
	"regexp"
	"strings"

	"golang.org/x/net/html"
	"golang.org/x/net/html/atom"
)

// A marker is a paragraph standing alone as [[name key="value" ...]], the
// shape [[toc]] already has. Site mode adds several; each expands to plain
// HTML and the container around it decides how it looks. Names are
// lowercase and values double-quoted, so a sentence that happens to hold
// brackets is never read as one.
type marker struct {
	node  *html.Node
	name  string
	attrs map[string]string
}

var (
	markerRe     = regexp.MustCompile(`^\[\[([a-z][a-z-]*)((?:\s+[a-z][a-z-]*="[^"]*")*)\s*\]\]$`)
	markerAttrRe = regexp.MustCompile(`([a-z][a-z-]*)="([^"]*)"`)
)

// navMarkerNames are the markers that need a site: outside one they are
// warned about and left as written.
var navMarkerNames = map[string]bool{
	"content": true, "pages": true, "breadcrumb": true, "prev-next": true, "search": true,
}

// markerText returns a paragraph's text when it is made only of text and
// links. GFM turns a bare URL into an <a>, so a marker whose attribute holds
// one is no longer a single text node; reading the link's text back keeps it
// a marker. A paragraph holding anything else — a code span, emphasis — is
// prose.
func markerText(p *html.Node) (string, bool) {
	var b strings.Builder
	for c := p.FirstChild; c != nil; c = c.NextSibling {
		switch {
		case c.Type == html.TextNode:
			b.WriteString(c.Data)
		case c.Type == html.ElementNode && c.DataAtom == atom.A:
			b.WriteString(textOf(c))
		default:
			return "", false
		}
	}
	return strings.TrimSpace(b.String()), true
}

// findMarkers returns every marker paragraph in root in document order.
// [[toc]] is left to the contents list transform, which owns it.
func findMarkers(root *html.Node) []marker {
	var out []marker
	walk(root, func(n *html.Node) {
		if n.Type != html.ElementNode || n.DataAtom != atom.P {
			return
		}
		s, ok := markerText(n)
		if !ok {
			return
		}
		m := markerRe.FindStringSubmatch(s)
		if m == nil || m[1] == "toc" {
			return
		}
		attrs := map[string]string{}
		for _, a := range markerAttrRe.FindAllStringSubmatch(m[2], -1) {
			attrs[a[1]] = a[2]
		}
		out = append(out, marker{node: n, name: m[1], attrs: attrs})
	})
	return out
}

// replaceMarker puts nodes where the marker's paragraph was, and removes it.
func replaceMarker(m marker, nodes ...*html.Node) {
	for _, n := range nodes {
		if n != nil {
			m.node.Parent.InsertBefore(n, m.node)
		}
	}
	m.node.Parent.RemoveChild(m.node)
}

// elem builds an element; attrs are key, value pairs, rendered in order.
func elem(tag string, attrs ...string) *html.Node {
	n := &html.Node{Type: html.ElementNode, Data: tag, DataAtom: atom.Lookup([]byte(tag))}
	for i := 0; i+1 < len(attrs); i += 2 {
		n.Attr = append(n.Attr, html.Attribute{Key: attrs[i], Val: attrs[i+1]})
	}
	return n
}

// textNode builds a text node.
func textNode(s string) *html.Node { return &html.Node{Type: html.TextNode, Data: s} }
```

`frontref.go`:

```go
package md2html

import (
	"fmt"
	"os"
	"path/filepath"
	"strings"
)

// resolveRefs returns meta with the value of each of keys that has the form
// @path#key replaced by key's value in the front matter of the file at path,
// relative to dir. Only keys are looked at: a reference resolves where
// md2html reads the key as data (a [[list]] key, a {name} template, a search
// facet), and every other value stays as written, unwarned, so a page with
// no markers is unchanged by references existing. A value found is used as
// written: one that is itself a reference is not followed, so references
// cannot loop. A reference that cannot be resolved becomes empty, so its @
// text never reaches a page, and is warned about.
func resolveRefs(meta map[string]string, dir string, keys []string, warn func(string)) map[string]string {
	if meta == nil {
		return nil
	}
	say := func(format string, args ...any) {
		if warn != nil {
			warn(fmt.Sprintf(format, args...))
		}
	}
	out := make(map[string]string, len(meta))
	for k, v := range meta {
		out[k] = v
	}
	for _, k := range keys {
		k = strings.ToLower(k)
		v, ok := meta[k]
		if !ok || !strings.HasPrefix(v, "@") {
			continue
		}
		file, key, ok := strings.Cut(v[1:], "#")
		if !ok || file == "" || key == "" {
			say("front matter %s %q is not @file#key; using it as written", k, v)
			continue
		}
		p := filepath.FromSlash(file)
		if !filepath.IsAbs(p) {
			p = filepath.Join(dir, p)
		}
		src, err := os.ReadFile(p)
		if err != nil {
			say("front matter %s refers to %s, which cannot be read; leaving it empty", k, file)
			out[k] = ""
			continue
		}
		ref, _, _ := splitFrontMatter(src)
		val, found := ref[strings.ToLower(key)]
		switch {
		case !found:
			say("front matter %s refers to %s in %s, which has no such key; leaving it empty", k, key, file)
			out[k] = ""
		case strings.HasPrefix(val, "@"):
			say("front matter %s refers to %s#%s, which is itself a reference; not following it", k, file, key)
			out[k] = ""
		default:
			out[k] = val
		}
	}
	return out
}
```

```go
package md2html

import (
	"fmt"
	"os"
	"path/filepath"
	"regexp"
	"sort"
	"strings"

	"golang.org/x/net/html"
)

// listItem is one entry of a [[list]] or [[subdirs]]: its value and, for a
// symlink, the name of the directory it points at.
type listItem struct{ item, target string }

var templateRe = regexp.MustCompile(`\{([a-z][a-z0-9-]*)\}`)

// listMarkers expands [[list]] and [[subdirs]], which work on any page.
// meta is the front matter of the file holding the markers, which their
// templates read, and dir is its directory, which [[subdirs]] paths are
// relative to.
func listMarkers(meta map[string]string, dir string, warn func(string)) Transform {
	say := func(format string, args ...any) {
		if warn != nil {
			warn(fmt.Sprintf(format, args...))
		}
	}
	return Transform{Name: "listMarkers", Fn: func(root *html.Node) error {
		ms := findMarkers(root)
		// References resolve here, for the keys these markers read and no
		// others (see resolveRefs).
		meta := resolveRefs(meta, dir, markerKeys(ms), warn)
		for _, m := range ms {
			var items []listItem
			switch m.name {
			case "list":
				items = valueItems(m.attrs["key"], meta, say)
			case "subdirs":
				items = subdirItems(m.attrs, dir, say)
			default:
				continue
			}
			replaceMarker(m, renderList(m, items, meta, say))
		}
		return nil
	}}
}

func valueItems(key string, meta map[string]string, say func(string, ...any)) []listItem {
	if key == "" {
		say("[[list]] has no key attribute; it lists nothing")
		return nil
	}
	v, ok := meta[strings.ToLower(key)]
	if !ok {
		say("[[list]] key %q is not in the front matter; it lists nothing", key)
		return nil
	}
	var items []listItem
	for _, s := range strings.Split(v, ",") {
		if s = strings.TrimSpace(s); s != "" {
			items = append(items, listItem{item: s})
		}
	}
	return items
}

func subdirItems(attrs map[string]string, dir string, say func(string, ...any)) []listItem {
	p := attrs["path"]
	if p == "" {
		say("[[subdirs]] has no path attribute; it lists nothing")
		return nil
	}
	if !filepath.IsAbs(p) {
		p = filepath.Join(dir, filepath.FromSlash(p))
	}
	entries, err := os.ReadDir(p)
	if err != nil {
		say("[[subdirs]] cannot read %s; it lists nothing", attrs["path"])
		return nil
	}
	match := attrs["match"]
	if match == "" {
		match = "*"
	}
	var links, dirs []listItem
	for _, e := range entries {
		name := e.Name()
		if strings.HasPrefix(name, ".") {
			continue
		}
		full := filepath.Join(p, name)
		if e.Type()&os.ModeSymlink != 0 {
			st, err := os.Stat(full)
			if err != nil {
				say("[[subdirs]] symlink %s points at nothing; leaving it out", name)
				continue
			}
			if !st.IsDir() {
				continue
			}
			target, _ := os.Readlink(full)
			links = append(links, listItem{item: name, target: filepath.Base(target)})
			continue
		}
		if !e.IsDir() {
			continue
		}
		if ok, _ := filepath.Match(match, name); ok {
			dirs = append(dirs, listItem{item: name})
		}
	}
	sort.Slice(links, func(i, j int) bool { return links[i].item < links[j].item })
	switch s := attrs["sort"]; s {
	case "name":
		sort.Slice(dirs, func(i, j int) bool { return dirs[i].item < dirs[j].item })
	case "", "version":
		sort.Slice(dirs, func(i, j int) bool { return versionCompare(dirs[i].item, dirs[j].item) > 0 })
	default:
		say("[[subdirs]] sort %q is not version or name; sorting by version", s)
		sort.Slice(dirs, func(i, j int) bool { return versionCompare(dirs[i].item, dirs[j].item) > 0 })
	}
	return append(links, dirs...)
}

// versionCompare orders two names by their runs of digits as numbers and
// the text between them as text, so v0.13 is above v0.9.
func versionCompare(a, b string) int {
	ra, rb := versionRuns(a), versionRuns(b)
	for i := 0; i < len(ra) && i < len(rb); i++ {
		x, y := ra[i], rb[i]
		if isDigits(x) && isDigits(y) {
			x, y = strings.TrimLeft(x, "0"), strings.TrimLeft(y, "0")
			if len(x) != len(y) {
				return cmpInt(len(x), len(y))
			}
		}
		if c := strings.Compare(x, y); c != 0 {
			return c
		}
	}
	return cmpInt(len(ra), len(rb))
}

func versionRuns(s string) []string {
	var runs []string
	start := 0
	for i := 1; i <= len(s); i++ {
		if i == len(s) || isDigit(s[i]) != isDigit(s[i-1]) {
			runs = append(runs, s[start:i])
			start = i
		}
	}
	return runs
}

func isDigit(c byte) bool { return c >= '0' && c <= '9' }

func isDigits(s string) bool { return s != "" && isDigit(s[0]) }

func cmpInt(a, b int) int {
	switch {
	case a < b:
		return -1
	case a > b:
		return 1
	}
	return 0
}

// markerKeys returns the front matter keys the list markers in ms read, in
// document order: a [[list]]'s key, and each {name} in a template that is
// not one of the marker's own variables.
func markerKeys(ms []marker) []string {
	seen := map[string]bool{}
	var keys []string
	add := func(k string) {
		if k = strings.ToLower(k); k != "" && !seen[k] {
			seen[k] = true
			keys = append(keys, k)
		}
	}
	for _, m := range ms {
		if m.name != "list" && m.name != "subdirs" {
			continue
		}
		if m.name == "list" {
			add(m.attrs["key"])
		}
		for _, a := range []string{"link", "text", "current"} {
			for _, t := range templateRe.FindAllString(m.attrs[a], -1) {
				if n := t[1 : len(t)-1]; n != "item" && n != "target" {
					add(n)
				}
			}
		}
	}
	return keys
}

// expandTemplate fills {name} from vars, then from meta. An unknown name
// is warned about and expands to nothing.
func expandTemplate(tpl string, vars, meta map[string]string, say func(string, ...any)) string {
	return templateRe.ReplaceAllStringFunc(tpl, func(m string) string {
		name := m[1 : len(m)-1]
		if v, ok := vars[name]; ok {
			return v
		}
		if v, ok := meta[name]; ok {
			return v
		}
		say("template %s names no front matter key; it expands to nothing", m)
		return ""
	})
}

// renderList builds the list: a <ul> of links, or with as="inline" a
// paragraph of links separated by commas. Nothing is rendered for an empty list.
func renderList(m marker, items []listItem, meta map[string]string, say func(string, ...any)) *html.Node {
	if len(items) == 0 {
		return nil
	}
	text := m.attrs["text"]
	if text == "" {
		text = "{item}"
	}
	current := ""
	if c, ok := m.attrs["current"]; ok {
		current = expandTemplate(c, nil, meta, say)
	}
	link, hasLink := m.attrs["link"]
	if !hasLink {
		say("[[%s]] has no link attribute; listing its entries as text", m.name)
	}
	inline := m.attrs["as"] == "inline"
	if as := m.attrs["as"]; as != "" && as != "inline" && as != "list" {
		say("[[%s]] as %q is not list or inline; rendering a list", m.name, as)
	}
	var box *html.Node
	if inline {
		// A paragraph, not a span: the marker was a paragraph of its own, so
		// the run of links takes its place as one.
		box = elem("p", "class", "md2html-list md2html-inline")
	} else {
		box = elem("ul", "class", "md2html-list")
	}
	for i, it := range items {
		vars := map[string]string{"item": it.item, "target": it.target}
		label := textNode(expandTemplate(text, vars, meta, say))
		var entry *html.Node
		if hasLink {
			entry = elem("a", "href", expandTemplate(link, vars, meta, say))
			if current != "" && it.item == current {
				entry.Attr = append(entry.Attr, html.Attribute{Key: "aria-current", Val: "true"})
			}
			entry.AppendChild(label)
		} else {
			entry = label
		}
		if inline {
			if i > 0 {
				box.AppendChild(textNode(", "))
			}
			box.AppendChild(entry)
			continue
		}
		li := elem("li")
		li.AppendChild(entry)
		box.AppendChild(li)
	}
	return box
}
```

```go
// from a crawl, and Convert uses it through Options.Site. Convert calls in

	Warnings []Warning

	shellDir  string

type siteNode struct {
	name     string // file stem or directory name
	label    string
	section  string // slug of the top-level node holding it; "" at the root
	path     string // a directory's path, for warnings
	doc      *Doc
	isDir    bool
	hidden   bool
	hasOrder bool
	order    int

	children []*siteNode

// BuildSite lays out the site for a crawl, with the page at shell as the
// shell every page is wrapped in. The shell is a template: BuildSite drops
// it from res.Docs, so it is never written. Its front matter must say
// site: true and it must hold exactly one [[content]] marker.
func BuildSite(res *CrawlResult, shell string, opt CrawlOptions) (*Site, error) {
	shellSrc, err := resolve(shell)
	if err != nil {
		return nil, err
	}
	raw, err := os.ReadFile(shellSrc)
	if err != nil {
		return nil, fmt.Errorf("site shell: %w", err)
	}
	meta, body, malformed := splitFrontMatter(raw)
	if malformed || meta["site"] != "true" {
		return nil, fmt.Errorf("%s is not a site shell: its front matter must say site: true", shell)
	}
	s := &Site{shellSrc: shellSrc, shellDir: filepath.Dir(shellSrc), shellBody: body,
		base: res.Base, crawl: opt}
	// Kept as written: the list markers resolve the keys they read, per
	// page, as on any page.
	s.shellMeta = meta
	parsed, err := parseDoc(body)
	if err != nil {
		return nil, fmt.Errorf("site shell %s: %w", shell, err)
	}
	contents := 0
	for _, m := range findMarkers(parsed) {
		if m.name == "content" {
			contents++
		}
	}
	if contents != 1 {
		return nil, fmt.Errorf("%s needs exactly one [[content]] marker; it has %d", shell, contents)
	}
	s.shellTOC = len(findTOCMarkers(parsed)) > 0
	for _, f := range strings.Split(s.shellMeta["search-facets"], ",") {
		if f = strings.ToLower(strings.TrimSpace(f)); f != "" {
			s.facets = append(s.facets, f)
		}
	}

	kept := res.Docs[:0]
	for _, d := range res.Docs {
		if d.Src != shellSrc {
			kept = append(kept, d)
		}
	}
	res.Docs = kept

	outDir := opt.OutDir
	if outDir != "" {
		if outDir, err = filepath.Abs(outDir); err != nil {
			return nil, err
		}
	}
	s.outRoot = filepath.Dir(outputPath(filepath.Join(res.Base, "index.md"), res.Base, outDir))
	s.outBySrc = make(map[string]string, len(res.Docs))
	for _, d := range res.Docs {
		s.outBySrc[d.Src] = d.Out
	}
	s.buildTree(res.Docs)
	return s, nil
}

func (s *Site) warn(src, msg string) { s.Warnings = append(s.Warnings, Warning{src, msg}) }

// buildTree places every document below the run's base: a directory is a
// node, its index.md its page, and a document from outside the base is
// written but has no place.
func (s *Site) buildTree(docs []Doc) {
	s.root = &siteNode{isDir: true, path: s.base}
	s.bySrc = map[string]*siteNode{}
	dirs := map[string]*siteNode{"": s.root}
	var dirFor func(rel string) *siteNode
	dirFor = func(rel string) *siteNode {
		if n, ok := dirs[rel]; ok {
			return n
		}
		parentRel := path.Dir(rel)
		if parentRel == "." {
			parentRel = ""
		}
		parent := dirFor(parentRel)
		n := &siteNode{name: path.Base(rel), isDir: true, parent: parent,
			path: filepath.Join(s.base, filepath.FromSlash(rel))}
		parent.children = append(parent.children, n)
		dirs[rel] = n
		return n
	}
	for i := range docs {
		d := &docs[i]
		rel, err := filepath.Rel(s.base, d.Src)
		if err != nil || rel == ".." || strings.HasPrefix(rel, ".."+string(filepath.Separator)) {
			s.warn(d.Src, fmt.Sprintf("is outside the site's root %s; it is written but has no place in the site's navigation", s.base))
			continue
		}
		rel = filepath.ToSlash(rel)
		dirRel := path.Dir(rel)
		if dirRel == "." {
			dirRel = ""
		}
		dir := dirFor(dirRel)
		stem := strings.TrimSuffix(path.Base(rel), path.Ext(rel))
		n := dir
		if !strings.EqualFold(stem, "index") || dir.doc != nil {
			n = &siteNode{name: stem, parent: dir}
			dir.children = append(dir.children, n)
		}
		n.doc = d
		s.bySrc[d.Src] = n
		s.applyMeta(n, d)
	}
	var finish func(n *siteNode)
	finish = func(n *siteNode) {
		if n.isDir && n.doc == nil {
			n.label = n.name
			if n != s.root {
				s.warn(n.path, "has no index.md; the site lists it by its directory name")
			}
		}
		for _, c := range n.children {
			finish(c)
		}
		sort.SliceStable(n.children, func(i, j int) bool { return lessNode(n.children[i], n.children[j]) })
	}
	finish(s.root)
	for _, top := range s.root.children {
		slug := slugify(top.name)
		var mark func(n *siteNode)
		mark = func(n *siteNode) {
			n.section = slug
			for _, c := range n.children {
				mark(c)
			}
		}
		mark(top)
	}
	var visit func(n *siteNode)
	visit = func(n *siteNode) {
		if n.hidden {
			return
		}
		if n.doc != nil {
			s.order = append(s.order, n)
		}
		for _, c := range n.children {
			visit(c)
		}
	}
	visit(s.root)
}

// applyMeta reads a page's navigation keys. A hidden page takes its
// subtree with it: a directory whose index is hidden is hidden whole.
func (s *Site) applyMeta(n *siteNode, d *Doc) {
	n.label = d.Title
	if t := d.Meta["nav-title"]; t != "" {
		n.label = t
	}
	if v := d.Meta["nav-order"]; v != "" {
		if i, err := strconv.Atoi(v); err == nil {
			n.order, n.hasOrder = i, true
		} else {
			s.warn(d.Src, fmt.Sprintf("front matter nav-order %q is not a whole number; ignoring it", v))
		}
	}
	switch v := d.Meta["nav"]; v {
	case "":
	case "hidden":
		n.hidden = true
	default:
		s.warn(d.Src, fmt.Sprintf("front matter nav %q is not hidden; ignoring it", v))
	}
}

// lessNode orders siblings: those with a nav-order first, by it, then the
// rest by label, case-insensitively, with the name breaking ties so the
// order never depends on the crawl's.
func lessNode(a, b *siteNode) bool {
	if a.hasOrder != b.hasOrder {
		return a.hasOrder
	}
	if a.hasOrder && a.order != b.order {
		return a.order < b.order
	}
	if la, lb := strings.ToLower(a.label), strings.ToLower(b.label); la != lb {
		return la < lb
	}
	return a.name < b.name
}

// section returns the slug of the top-level node holding the page at src,
// or "" for the root page or a page the tree could not place.
func (s *Site) section(src string) string {
	if n := s.bySrc[src]; n != nil {
		return n.section
	}
	return ""
}

// outline renders the tree as indented labels, for tests.
func (s *Site) outline() string {
	var b strings.Builder
	var rec func(n *siteNode, depth int)
	rec = func(n *siteNode, depth int) {
		for _, c := range n.children {
			mark := ""
			if c.hidden {
				mark = " (hidden)"
			}
			if c.doc == nil {
				mark += " (label)"
			}
			fmt.Fprintf(&b, "%s%s%s\n", strings.Repeat("  ", depth), c.label, mark)
			rec(c, depth+1)
		}
	}
	rec(s.root, 0)
	return b.String()
}
```

```go
package md2html

import (
	"bytes"
	"fmt"
	"strings"

	"golang.org/x/net/html"
)

// wrap returns the shell, rendered for the page at src, with the page's
// body moved into its [[content]], which becomes the page's
// <main class="md2html">. content is the page's tree after every transform;
// transforms are the page's own, which the shell gets too, minus the page's
// link rewrite. The shell is parsed afresh per page because its links and
// markers differ from page to page.
//
// Order matters. The shell's links are rewritten first, for this page,
// before anything else adds links. Its [[toc]] markers are set aside, so
// the page's toc transform cannot list the shell's own headings. Its
// markers expand next, then the page's transforms run over the shell alone.
// Then any shell id the page also uses is renumbered, and only after that
// do the contents lists go in, since their links point into the page and
// must not be renumbered with the shell's. The page's body goes in last, so
// nothing is transformed twice. Contents lists under a shell are always
// inline: the shell places them.
func (s *Site) wrap(content *html.Node, src string, transforms []Transform, label string, warn func(string)) (*html.Node, error) {
	var buf bytes.Buffer
	if err := newParser(warn, chartContext{off: true}).Convert(s.shellBody, &buf); err != nil {
		return nil, err
	}
	shell, err := parseFragment(buf.Bytes())
	if err != nil {
		return nil, err
	}
	out := s.outBySrc[src]
	if err := LinkRewrite(linkMapFor(ExtractLinks(shell, s.shellDir), out, s.outBySrc, s.crawl)).Fn(shell); err != nil {
		return nil, err
	}
	if label == "" {
		label = tocLabel
	}
	// An element no transform knows holds each [[toc]]'s place.
	var tocSlots []*html.Node
	for _, m := range findTOCMarkers(shell) {
		slot := elem("md2html-toc-slot")
		m.Parent.InsertBefore(slot, m)
		m.Parent.RemoveChild(m)
		tocSlots = append(tocSlots, slot)
	}
	ts := append([]Transform{listMarkers(s.shellMeta, s.shellDir, warn)}, transforms...)
	for _, t := range ts {
		if err := t.Fn(shell); err != nil {
			return nil, fmt.Errorf("site shell: transform %s: %w", t.Name, err)
		}
	}
	renumberShellIDs(shell, content)
	for _, slot := range tocSlots {
		if nav := buildTOC(headingNodes(content), label, false); nav != nil {
			slot.Parent.InsertBefore(nav, slot)
		}
		slot.Parent.RemoveChild(slot)
	}
	for _, m := range findMarkers(shell) {
		if m.name != "content" {
			continue
		}
		main := elem("main", "class", "md2html")

// renumberShellIDs keeps the page's ids and renumbers any shell id the page
// also uses, as HeadingAnchors numbers a repeated heading, then points the
// shell's own "#id" links at the new ids. The page wins because other pages
// link to its ids; nothing outside links into the shell.
func renumberShellIDs(shell, content *html.Node) {
	ids := func(root *html.Node) map[string]bool {
		seen := map[string]bool{}
		walk(root, func(n *html.Node) {
			if n.Type == html.ElementNode {
				if id, ok := attr(n, "id"); ok && id != "" {
					seen[id] = true
				}
			}
		})
		return seen
	}
	page, used := ids(content), ids(shell)
	for id := range page {
		used[id] = true
	}
	renamed := map[string]string{}
	walk(shell, func(n *html.Node) {
		if n.Type != html.ElementNode {
			return
		}
		id, ok := attr(n, "id")
		if !ok || !page[id] {
			return
		}
		if _, done := renamed[id]; done {
			return // the shell repeats its own id; HeadingAnchors leaves that as written too
		}
		next := id
		for i := 1; used[next]; i++ {
			next = fmt.Sprintf("%s-%d", id, i)
		}
		used[next] = true
		renamed[id] = next
		setAttr(n, "id", next)
	})
	if len(renamed) == 0 {
		return
	}
	walk(shell, func(n *html.Node) {
		if n.Type != html.ElementNode {
			return
		}
		for i, a := range n.Attr {
			if a.Key == "href" && strings.HasPrefix(a.Val, "#") {
				if to, ok := renamed[a.Val[1:]]; ok {
					n.Attr[i].Val = "#" + to
				}
			}
		}
	})
}
```

```go
package md2html

import (
	"fmt"
	"path/filepath"
	"strconv"

	"golang.org/x/net/html"

// navMarkers expands the markers that need the site's tree, for the page
// at src: in the shell, and in a site page's own body.
func (s *Site) navMarkers(src string, warn func(string)) Transform {
	say := func(format string, args ...any) {
		if warn != nil {
			warn(fmt.Sprintf(format, args...))
		}
	}
	return Transform{Name: "navMarkers", Fn: func(root *html.Node) error {
		page := s.bySrc[src]
		from := s.outBySrc[src]
		for _, m := range findMarkers(root) {
			switch m.name {
			case "pages":
				replaceMarker(m, s.pagesList(m, page, from, say))
			case "breadcrumb":
				replaceMarker(m, s.breadcrumb(page, from))
			case "prev-next":
				replaceMarker(m, s.prevNext(page, from))
			}
		}
		return nil
	}}
}

// href is the link from the page written at from to the file at to.
func (s *Site) href(from, to string) string {
	rel, err := filepath.Rel(filepath.Dir(from), to)
	if err != nil {
		return filepath.ToSlash(to)
	}
	return encodePath(filepath.ToSlash(rel))
}

func (s *Site) pagesList(m marker, page *siteNode, from string, say func(string, ...any)) *html.Node {
	depth := -1
	if v, ok := m.attrs["depth"]; ok {
		if d, err := strconv.Atoi(v); err == nil && d >= 1 {
			depth = d
		} else {
			say("[[pages]] depth %q is not a whole number of at least 1; listing every level", v)
		}
	}
	start := s.root
	switch v := m.attrs["from"]; v {
	case "", "root":
	case "section":
		start = nil
		for n := page; n != nil && n.parent != nil; n = n.parent {
			if n.parent == s.root {
				start = n
			}
		}
		if start == nil {
			return nil // the root page has no section
		}
	default:
		say("[[pages]] from %q is not root or section; listing from the root", v)
	}
	return s.pagesLevel(start, page, from, depth)
}

func (s *Site) pagesLevel(n, page *siteNode, from string, depth int) *html.Node {
	var shown []*siteNode
	for _, c := range n.children {
		if !c.hidden {
			shown = append(shown, c)
		}
	}
	if len(shown) == 0 || depth == 0 {
		return nil
	}
	ul := elem("ul", "class", "md2html-pages")
	for _, c := range shown {
		li := elem("li")
		if contains(c, page) {
			li.Attr = append(li.Attr, html.Attribute{Key: "class", Val: "md2html-branch"})
		}
		li.AppendChild(s.nodeLink(c, page, from))
		if sub := s.pagesLevel(c, page, from, depth-1); sub != nil {
			li.AppendChild(sub)
		}
		ul.AppendChild(li)
	}
	return ul
}

// nodeLink is a node's link, marked when it is the page itself, or its
// label when the node has no page.
func (s *Site) nodeLink(n, page *siteNode, from string) *html.Node {
	if n.doc == nil {
		span := elem("span", "class", "md2html-label")
		span.AppendChild(textNode(n.label))
		return span
	}
	a := elem("a", "href", s.href(from, n.doc.Out))
	if n == page {
		a.Attr = append(a.Attr, html.Attribute{Key: "aria-current", Val: "page"})
	}
	a.AppendChild(textNode(n.label))
	return a
}

// contains reports whether page is n or below it.
func contains(n, page *siteNode) bool {
	for p := page; p != nil; p = p.parent {
		if p == n {
			return true
		}
	}
	return false
}

func (s *Site) breadcrumb(page *siteNode, from string) *html.Node {
	if page == nil {
		return nil
	}
	var chain []*siteNode
	for n := page; n != nil; n = n.parent {
		chain = append([]*siteNode{n}, chain...)
	}
	ol := elem("ol", "class", "md2html-breadcrumb")
	for _, n := range chain {
		if n == s.root && n.doc == nil {
			continue
		}
		li := elem("li")
		li.AppendChild(s.nodeLink(n, page, from))
		ol.AppendChild(li)
	}
	// Its own landmark: a breadcrumb appears once and has one obvious name,
	// unlike [[pages]], which a shell may show twice with two labels.
	nav := elem("nav", "aria-label", "Breadcrumb")
	nav.AppendChild(ol)
	return nav
}

func (s *Site) prevNext(page *siteNode, from string) *html.Node {
	at := -1
	for i, n := range s.order {
		if n == page {
			at = i
		}
	}
	if at < 0 {
		return nil
	}
	div := elem("nav", "class", "md2html-prev-next", "aria-label", "Previous and next")
	add := func(n *siteNode, class, rel, dir string) {
		a := elem("a", "href", s.href(from, n.doc.Out), "class", class, "rel", rel)
		d := elem("span", "class", "md2html-dir")
		d.AppendChild(textNode(dir))
		t := elem("span", "class", "md2html-title")
		t.AppendChild(textNode(n.label))
		a.AppendChild(d)
		a.AppendChild(textNode(" "))
		a.AppendChild(t)
		div.AppendChild(a)
	}
	if at > 0 {
		add(s.order[at-1], "md2html-prev", "prev", "Previous")
	}
	if at < len(s.order)-1 {
		add(s.order[at+1], "md2html-next", "next", "Next")
	}
	return div
}
```

```go
// searchEntry is one page in the search index.
type searchEntry struct {
	URL      string            `json:"url"`
	Title    string            `json:"title"`
	Headings []searchHeading   `json:"headings,omitempty"`
	Terms    []string          `json:"terms,omitempty"`
	Text     string            `json:"text,omitempty"`
	Facets   map[string]string `json:"facets,omitempty"`
}

type searchHeading struct {
	Text string `json:"text"`
	ID   string `json:"id"`
}

// searchTextLimit bounds the first paragraph kept per page.
const searchTextLimit = 300

// IndexName is the search index's file name, at the site's output root.
const IndexName = "md2html-search.js"

// record adds the page at src to the search index, replacing any entry it
// already has. root is the page's own tree, before the shell wraps it.
func (s *Site) record(src, title string, meta map[string]string, root *html.Node) {
	rel, err := filepath.Rel(s.outRoot, s.outBySrc[src])
	if err != nil {
		return
	}
	e := searchEntry{URL: filepath.ToSlash(rel), Title: title}
	for _, h := range headingNodes(root) {
		if id, ok := attr(h, "id"); ok && id != "" {
			if t := strings.TrimSpace(headingText(h)); t != "" {
				e.Headings = append(e.Headings, searchHeading{Text: t, ID: id})
			}
		}
	}
	walk(root, func(n *html.Node) {
		if n.Type != html.ElementNode {
			return
		}
		switch {
		case n.DataAtom == atom.Dt:
			if t := strings.TrimSpace(textOf(n)); t != "" {
				e.Terms = append(e.Terms, t)
			}
		case n.DataAtom == atom.P && e.Text == "" && !hasClass(n, "subtitle") && !hasClass(n, "docdate") && !hasClass(n, "eyebrow"):
			t := strings.Join(strings.Fields(textOf(n)), " ")
			if len(t) > searchTextLimit {
				t = t[:searchTextLimit]
			}
			e.Text = t
		}
	})
	for _, f := range s.facets {
		if v := meta[f]; v != "" {
			if e.Facets == nil {
				e.Facets = map[string]string{}
			}
			e.Facets[f] = v
		}
	}
	s.mu.Lock()
	defer s.mu.Unlock()
	for i, old := range s.entries {
		if old.URL == e.URL {
			s.entries[i] = e
			return
		}
	}
	s.entries = append(s.entries, e)
}

// IndexPath is where the search index belongs: the site's output root.
func (s *Site) IndexPath() string { return filepath.Join(s.outRoot, IndexName) }

// SearchIndex is the index as a script that sets window.md2htmlSearch.
// A script, not a data file, so a page opened from disk can load it: a
// browser blocks fetching a file:// URL but not a script tag. It starts
// with the provenance marker, so SafeWrite will replace it next run.
func (s *Site) SearchIndex() []byte {
	s.mu.Lock()
	entries := append([]searchEntry(nil), s.entries...)
	s.mu.Unlock()
	sort.Slice(entries, func(i, j int) bool { return entries[i].URL < entries[j].URL })
	if entries == nil {
		entries = []searchEntry{}
	}
	data, _ := json.Marshal(entries)
	return []byte("// " + Marker() + "\nwindow.md2htmlSearch = " + string(data) + ";\n")
}

// searchBox is what [[search]] expands to. It stays hidden until the
// runtime has the index, so a page without scripts shows no dead box.
func (s *Site) searchBox(from string) *html.Node {
	div := elem("div", "class", "md2html-search", "hidden", "", "data-index", s.href(from, s.IndexPath()))
	div.AppendChild(elem("input", "type", "search", "class", "md2html-search-input",
		"placeholder", "Search", "aria-label", "Search this site", "autocomplete", "off"))
	div.AppendChild(elem("ol", "class", "md2html-search-results"))
	return div
}
```

```go
  const box = document.querySelector(".md2html-search");
  if (!box) return;

  const list = box.querySelector(".md2html-search-results");

      let best = 0, href = e.url;
      if (e.title.toLowerCase().includes(q)) best = 4;
      for (const h of e.headings || []) {
        if (best < 3 && h.text.toLowerCase().includes(q)) { best = 3; href = e.url + "#" + h.id; }
```

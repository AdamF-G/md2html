# Plugins Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let md2html load data-only plugins that provide named styles, select and stack those styles per run (`--style`) or per page (`style:`), and ship a `claude-artifact` plugin.

**Architecture:** A plugin is a directory with an `md2html-plugin.json` manifest. A `PluginCache` loads plugins (embedded from `plugins/`, or from disk), validates them, and assembles a page's stylesheet from its selected styles: the default stylesheet, then each style's CSS in turn, with every `url()` asset inlined as a `data:` URI. `Convert` picks the page's style list (front matter, then run, then default) and hands the resulting CSS string to the existing `renderPage` and `renderFragment`, which don't change.

**Tech Stack:** Go 1.26, `encoding/json`, `embed`, `io/fs`. No new dependencies. Browser tests use chromedp in the separate `e2e` module.

**Spec:** `docs/specs/2026-10-11-plugins-design.md`. Read it before starting any task.

## Global Constraints

- Manifest filename: exactly `md2html-plugin.json`.
- Manifest `format`: this release reads `1` and refuses any other value.
- Plugin and style names match `^[a-z][a-z0-9-]*$`.
- The names `default` (plugin and style) are reserved for the built-in default plugin.
- Style `base`: `"default"` (the default value) or `"none"`; nothing else.
- Qualified style name: `plugin/style`.
- Assets inlined by extension: `woff2`, `woff`, `ttf`, `otf`, `svg`, `png`, `jpg`/`jpeg`, `gif`, `webp`. Anything else is an error.
- Refused in plugin CSS: `@import`; `url()` with a scheme (`http:`, `https:`, any `x:`), `//`, a leading `/`, or a path resolving outside the plugin directory (including through a symlink).
- Assembled stylesheet over 1 MB: convert with a warning.
- `claude-artifact` font budget: at most 150 KB of font files in total.
- Output with no style option must stay byte-identical to v0.9.0.
- No new module dependencies in the root `go.mod`.
- No JavaScript in plugins; `page.go`'s runtimes are untouched.
- Commit messages: conventional (`feat:`, `docs:`, `test:`), and **no `Co-Authored-By` or other attribution trailer**.
- Match the surrounding code's comment density and voice: comments explain *why*, in full sentences, as in `md2html.go` and `page.go`.

## Review Focus

1. **A layered style that sets light tokens only on bare `:root`.** The default stylesheet has a `:root[data-theme="light"]` block, which outranks bare `:root`. A page explicitly stamped light would then show the *default* palette under the plugin's dark-mode-aware styles. Expect the plugin's light palette in all three theme states. *Test:* Task 8, the theme-block equality check over every built-in style, which requires a `[data-theme="light"]` block. Also documented as a silent trap in Task 9.
2. **`url(#id)` fragment references in plugin CSS** (SVG filters, markers, `clip-path: url(#c)`). Expect these to pass through untouched, not be refused as a missing file. *Test:* Task 3 case `fragment reference passes through`.
3. **`url()` text inside a CSS comment or a `content: "…"` string.** Expect it to be left alone. A comment saying `/* was url(http://…) */` must not fail the load. *Test:* Task 3 cases `url in a comment` and `url in a string`.
4. **Front matter `plugins:` making the run's bare `--style` name ambiguous.** A page that loads a local plugin but does not set `style:` must keep the run's styles exactly. Expect the run's list to be resolved against the run's plugins only, and a warning that `plugins:` without `style:` has no effect. *Test:* Task 6 `TestPagePluginsWithoutStyleWarnAndKeepRunStyles`.
5. **Many pages converted in parallel against one shared cache, with a broken plugin.** Expect no data race, one read of the plugin, and the same error reported for each page. *Test:* Task 5 `TestStylesheetConcurrentSharedCache`, run with `-race`.

```go
package md2html

import (
	"encoding/json"
	"fmt"
	"io/fs"
	"regexp"
	"sort"
)

// ManifestName is the file that makes a directory an md2html plugin. It is
// named for the tool rather than generically, so a plugin is recognisable
// in a repository full of other tools' files, and so a future remote source
// can tell a repository is a plugin by this file alone.
const ManifestName = "md2html-plugin.json"

// pluginFormat is the one manifest format this release reads. A later
// format that only adds keys keeps this number; one that changes what an
// existing key means bumps it, and this release then refuses it rather than
// misreading it.
const pluginFormat = 1

// pluginName is the shape of a plugin or style name: short enough to type
// in front matter unquoted, and never mistakable for a path.
var pluginName = regexp.MustCompile(`^[a-z][a-z0-9-]*$`)

// reservedName belongs to the built-in default plugin and its one style, so
// that "style: default" always means the plain default.
const reservedName = "default"

// Plugin is one loaded plugin: its manifest's identity and what it
// provides. In this release that is styles only.
type Plugin struct {
	Name, Description string
	Styles            map[string]*Style

	key  string // cache identity: "builtin:<name>", or the real directory
	fsys fs.FS  // the plugin's files, rooted at its directory
	dir  string // the real directory on disk; "" for a built-in plugin
}

// Style is one named stylesheet a plugin provides.
type Style struct {
	Name, Description string
	// BaseNone means the style starts from nothing rather than from the
	// default stylesheet. Only the first style a page selects may.
	BaseNone bool

	css []string // CSS files, relative to the plugin directory, in order
}

// StyleNames returns the plugin's style names in sorted order.
func (p *Plugin) StyleNames() []string {
	names := make([]string, 0, len(p.Styles))
	for n := range p.Styles {
		names = append(names, n)
	}
	sort.Strings(names)
	return names
}

// parseManifest reads a manifest. where names the plugin in every message.
// builtin permits the reserved name, which only the default plugin uses.
//
// Unknown keys are warned about and skipped rather than refused, so that a
// plugin written for a later release that only adds keys still loads here.
func parseManifest(data []byte, where string, builtin bool, warn func(string)) (*Plugin, error) {
	fail := func(format string, a ...any) (*Plugin, error) {
		return nil, fmt.Errorf("plugin %s: "+format, append([]any{where}, a...)...)
	}
	var top map[string]json.RawMessage
	if err := json.Unmarshal(data, &top); err != nil {
		return fail("%s is not valid JSON: %v", ManifestName, err)
	}

	var format int
	if ok, err := take(top, "format", &format); err != nil {
		return fail("%s: format: %v", ManifestName, err)
	} else if !ok {
		return fail("%s has no format", ManifestName)
	}
	if format != pluginFormat {
		return fail("format %d is not supported by md2html %s, which reads format %d", format, Version, pluginFormat)
	}

	p := &Plugin{Styles: map[string]*Style{}}
	if ok, err := take(top, "name", &p.Name); err != nil {
		return fail("%s: name: %v", ManifestName, err)
	} else if !ok {
		return fail("%s has no name", ManifestName)
	}
	if err := checkName("name", p.Name, builtin); err != nil {
		return fail("%v", err)
	}
	if _, err := take(top, "description", &p.Description); err != nil {
		return fail("%s: description: %v", ManifestName, err)
	}

	var styles map[string]map[string]json.RawMessage
	if _, err := take(top, "styles", &styles); err != nil {
		return fail("%s: styles: %v", ManifestName, err)
	}
	for _, k := range sortedKeys(top) {
		if warn != nil {
			warn(fmt.Sprintf("plugin %s: unknown key %q in %s; ignoring it", where, k, ManifestName))
		}
	}
	if len(styles) == 0 {
		return fail("provides nothing: %s needs a non-empty styles", ManifestName)
	}

	for _, name := range sortedKeys(styles) {
		raw := styles[name]
		if err := checkName("style name", name, builtin); err != nil {
			return fail("%v", err)
		}
		s := &Style{Name: name}
		if _, err := take(raw, "description", &s.Description); err != nil {
			return fail("style %q: description: %v", name, err)
		}
		var base string
		if _, err := take(raw, "base", &base); err != nil {
			return fail("style %q: base: %v", name, err)
		}
		switch base {
		case "", "default":
		case "none":
			s.BaseNone = true
		default:
			return fail("style %q: base %q is not default or none", name, base)
		}
		if _, err := take(raw, "css", &s.css); err != nil {
			return fail("style %q: css: %v", name, err)
		}
		if len(s.css) == 0 {
			return fail("style %q has no css files", name)
		}
		for _, k := range sortedKeys(raw) {
			if warn != nil {
				warn(fmt.Sprintf("plugin %s: unknown key %q in style %q; ignoring it", where, k, name))
			}
		}
		p.Styles[name] = s
	}
	return p, nil
}

// checkName holds a plugin or style name to pluginName, and keeps the
// reserved name for the built-in default plugin.
func checkName(what, name string, builtin bool) error {
	if !pluginName.MatchString(name) {
		return fmt.Errorf("%s %q is not lowercase letters, digits and hyphens starting with a letter", what, name)
	}
	if name == reservedName && !builtin {
		return fmt.Errorf("%s %q is reserved for the built-in default plugin", what, name)
	}
	return nil
}

// take decodes m[key] into dst and removes it from m, so that whatever is
// left in m afterwards is the keys nobody asked for. It reports whether the
// key was present.
func take(m map[string]json.RawMessage, key string, dst any) (bool, error) {
	raw, ok := m[key]
	if !ok {
		return false, nil
	}
	delete(m, key)
	return true, json.Unmarshal(raw, dst)
}

// sortedKeys returns m's keys in sorted order, so that messages about them
// come out the same way on every run.
func sortedKeys[V any](m map[string]V) []string {
	keys := make([]string, 0, len(m))
	for k := range m {
		keys = append(keys, k)
	}
	sort.Strings(keys)
	return keys
}
```

```go
package md2html

import (
	"encoding/base64"
	"fmt"
	"path"
	"strings"
)

// assetTypes are the files a style may inline, by extension. Fonts and
// images are what a stylesheet references; anything else in a url() is
// more likely a mistake than an asset, so it is refused rather than guessed.
var assetTypes = map[string]string{
	".woff2": "font/woff2",
	".woff":  "font/woff",
	".ttf":   "font/ttf",
	".otf":   "font/otf",
	".svg":   "image/svg+xml",
	".png":   "image/png",
	".jpg":   "image/jpeg",
	".jpeg":  "image/jpeg",
	".gif":   "image/gif",
	".webp":  "image/webp",
}

// inlineAssets replaces every url() in css that names a file in the plugin
// with a data: URI of that file, so a page stays one file and fetches
// nothing: mermaid stays the only thing a page can load, and fragment
// output stays publishable as an Artifact, which allows no asset host.
//
// cssPath is the stylesheet's own path in the plugin, which relative URLs
// resolve against, as a browser would. read fetches a file by its path in
// the plugin and refuses one outside it.
//
// It scans rather than matching a pattern because the text "url(" can
// appear where it is not a URL, in a comment or a content string, and a
// comment noting an old CDN address must not fail the load. A fragment
// reference such as url(#shadow) names an element in the page, not a file,
// so it passes through, as does a data: URL already inline.
func inlineAssets(css, cssPath string, read func(rel string) ([]byte, error)) (string, error) {
	var b strings.Builder
	for i := 0; i < len(css); {
		rest := css[i:]
		switch {
		case strings.HasPrefix(rest, "/*"):
			end := strings.Index(rest[2:], "*/")
			n := len(rest)
			if end >= 0 {
				n = 2 + end + 2
			}
			b.WriteString(rest[:n])
			i += n
		case rest[0] == '"' || rest[0] == '\'':
			n := stringEnd(rest)
			b.WriteString(rest[:n])
			i += n
		case hasPrefixFold(rest, "@import"):
			return "", fmt.Errorf("%s: @import is not allowed; add the file to the style's css list instead", cssPath)
		case hasPrefixFold(rest, "url(") && (i == 0 || !isIdentByte(css[i-1])):
			end := strings.IndexByte(rest, ')')
			if end < 0 {
				return "", fmt.Errorf("%s: unclosed url(", cssPath)
			}
			raw := strings.TrimSpace(rest[4:end])
			ref := strings.Trim(raw, `"'`)
			out, err := inlineURL(ref, cssPath, read)
			if err != nil {
				return "", err
			}
			if out == "" {
				b.WriteString(rest[:end+1])
			} else {
				b.WriteString(`url("` + out + `")`)
			}
			i += end + 1
		default:
			b.WriteByte(css[i])
			i++
		}
	}
	return b.String(), nil
}

// inlineURL returns the data: URI for one url() reference, or "" for a
// reference left as written.
func inlineURL(ref, cssPath string, read func(string) ([]byte, error)) (string, error) {
	if strings.HasPrefix(ref, "#") || hasPrefixFold(ref, "data:") {
		return "", nil
	}
	if strings.HasPrefix(ref, "/") || strings.Contains(strings.SplitN(ref, "/", 2)[0], ":") {
		return "", fmt.Errorf("%s: url(%s) is not a relative path inside the plugin; a plugin cannot load anything at view time", cssPath, ref)
	}
	file, frag, _ := strings.Cut(ref, "#")
	file, _, _ = strings.Cut(file, "?")
	rel := path.Clean(path.Join(path.Dir(cssPath), file))
	if rel == ".." || strings.HasPrefix(rel, "../") {
		return "", fmt.Errorf("%s: url(%s) is outside the plugin", cssPath, ref)
	}
	mime, ok := assetTypes[strings.ToLower(path.Ext(rel))]
	if !ok {
		return "", fmt.Errorf("%s: url(%s): %q is not a font or image type md2html can inline", cssPath, ref, path.Ext(rel))
	}
	data, err := read(rel)
	if err != nil {
		return "", fmt.Errorf("%s: url(%s): %w", cssPath, ref, err)
	}
	uri := "data:" + mime + ";base64," + base64.StdEncoding.EncodeToString(data)
	if frag != "" {
		uri += "#" + frag
	}
	return uri, nil
}

// stringEnd returns the length of the CSS string literal s starts with,
// including both quotes, or len(s) if it never closes.
func stringEnd(s string) int {
	q := s[0]
	for i := 1; i < len(s); i++ {
		switch s[i] {
		case '\\':
			i++
		case q:
			return i + 1
		}
	}
	return len(s)
}

func hasPrefixFold(s, prefix string) bool {
	return len(s) >= len(prefix) && strings.EqualFold(s[:len(prefix)], prefix)
}

// isIdentByte reports whether c can be part of a CSS identifier, so that
// "my-url(" is not taken for "url(".
func isIdentByte(c byte) bool {
	return c == '-' || c == '_' || c >= '0' && c <= '9' || c >= 'a' && c <= 'z' || c >= 'A' && c <= 'Z'
}
```

Note: `url(//cdn/x)` takes the leading `/` branch. `url(http://…)` has a `:` in its first path segment, so it takes the scheme branch, as does any `x:` scheme.

```go
package md2html

import (
	"errors"
	"fmt"
	"io/fs"
	"os"
	"path"
	"path/filepath"
	"sort"
	"strings"
	"sync"
)

// PluginCache loads plugins and assembles stylesheets, keeping both, so a
// run that converts many pages reads each plugin and inlines its fonts
// once. It is safe for concurrent use: the CLI converts pages in parallel
// against one cache.
type PluginCache struct {
	mu      sync.Mutex
	plugins map[string]*pluginEntry // by real directory
	sheets  map[string]*sheetEntry  // by resolved style list; see stylesheet.go
}

// pluginEntry is one directory's load, done once. Its warnings are kept so
// that every caller hears them: a page loading a plugin another page
// already loaded is still told about that plugin's unknown keys.
type pluginEntry struct {
	once     sync.Once
	plugin   *Plugin
	warnings []string
	err      error
}

// NewPluginCache returns an empty cache.
func NewPluginCache() *PluginCache {
	return &PluginCache{plugins: map[string]*pluginEntry{}, sheets: map[string]*sheetEntry{}}
}

// Load reads and validates the plugin in dir. A relative dir is taken
// against baseDir, or the working directory when baseDir is empty.
//
// Entries are keyed by the directory with symlinks resolved, so two
// spellings of one plugin load it once and come back as one *Plugin.
// Errors are kept too: a broken plugin named by every page is read once and
// reported to each.
func (c *PluginCache) Load(dir, baseDir string, warn func(string)) (*Plugin, error) {
	p := dir
	if !filepath.IsAbs(p) && baseDir != "" {
		p = filepath.Join(baseDir, p)
	}
	abs, err := filepath.Abs(p)
	if err != nil {
		return nil, fmt.Errorf("plugin %s: %w", dir, err)
	}
	real, err := filepath.EvalSymlinks(abs)
	if err != nil {
		return nil, fmt.Errorf("plugin %s: %w", dir, err)
	}

	c.mu.Lock()
	e, ok := c.plugins[real]
	if !ok {
		e = &pluginEntry{}
		c.plugins[real] = e
	}
	c.mu.Unlock()

	e.once.Do(func() {
		e.plugin, e.err = loadDir(real, dir, func(w string) { e.warnings = append(e.warnings, w) })
	})
	if warn != nil {
		for _, w := range e.warnings {
			warn(w)
		}
	}
	return e.plugin, e.err
}

// LoadAll loads each of dirs, in order, stopping at the first error.
func (c *PluginCache) LoadAll(dirs []string, baseDir string, warn func(string)) ([]*Plugin, error) {
	var out []*Plugin
	for _, d := range dirs {
		p, err := c.Load(d, baseDir, warn)
		if err != nil {
			return nil, err
		}
		out = append(out, p)
	}
	return out, nil
}

// loadDir reads the plugin at real, a directory with symlinks resolved.
// where is how the caller named it, for messages.
func loadDir(real, where string, warn func(string)) (*Plugin, error) {
	fi, err := os.Stat(real)
	if err != nil {
		return nil, fmt.Errorf("plugin %s: %w", where, err)
	}
	if !fi.IsDir() {
		return nil, fmt.Errorf("plugin %s: not a directory", where)
	}
	data, err := os.ReadFile(filepath.Join(real, ManifestName))
	if errors.Is(err, fs.ErrNotExist) {
		return nil, fmt.Errorf("plugin %s: no %s in it", where, ManifestName)
	} else if err != nil {
		return nil, fmt.Errorf("plugin %s: %w", where, err)
	}
	p, err := parseManifest(data, where, false, warn)
	if err != nil {
		return nil, err
	}
	p.key, p.fsys, p.dir = real, os.DirFS(real), real
	return p, nil
}

// readFile reads rel, a slash-separated path in the plugin, refusing one
// that leads outside it: by "..", by being absolute, or, on disk, by a
// symlink pointing elsewhere. That is what stops a plugin pulling an
// arbitrary local file into every page it styles.
func (p *Plugin) readFile(rel string) ([]byte, error) {
	clean := path.Clean(rel)
	if !fs.ValidPath(clean) {
		return nil, fmt.Errorf("plugin %s: %s is outside the plugin", p.Name, rel)
	}
	if p.dir != "" {
		real, err := filepath.EvalSymlinks(filepath.Join(p.dir, filepath.FromSlash(clean)))
		if err != nil {
			return nil, fmt.Errorf("plugin %s: %w", p.Name, err)
		}
		if r, err := filepath.Rel(p.dir, real); err != nil || r == ".." || strings.HasPrefix(r, ".."+string(filepath.Separator)) {
			return nil, fmt.Errorf("plugin %s: %s is outside the plugin", p.Name, rel)
		}
	}
	b, err := fs.ReadFile(p.fsys, clean)
	if err != nil {
		return nil, fmt.Errorf("plugin %s: %w", p.Name, err)
	}
	return b, nil
}

// builtinPlugins parses the embedded plugins once. A built-in that does not
// parse is a defect in the build, not in anyone's input, and the tests load
// every one, so it cannot ship.
var builtinPlugins = sync.OnceValues(func() ([]*Plugin, error) {
	entries, err := fs.ReadDir(builtinFS, "plugins")
	if err != nil {
		return nil, err
	}
	var out []*Plugin
	for _, e := range entries {
		if !e.IsDir() {
			continue
		}
		root := "plugins/" + e.Name()
		data, err := fs.ReadFile(builtinFS, root+"/"+ManifestName)
		if err != nil {
			return nil, fmt.Errorf("built-in plugin %s: %w", e.Name(), err)
		}
		var warned error
		p, err := parseManifest(data, e.Name(), true, func(w string) { warned = errors.New(w) })
		if err != nil {
			return nil, err
		}
		if warned != nil {
			return nil, fmt.Errorf("built-in plugin must load without warnings: %w", warned)
		}
		if p.Name != e.Name() {
			return nil, fmt.Errorf("built-in plugin %s: its manifest names it %q", e.Name(), p.Name)
		}
		sub, err := fs.Sub(builtinFS, root)
		if err != nil {
			return nil, err
		}
		p.key, p.fsys = "builtin:"+p.Name, sub
		out = append(out, p)
	}
	sort.Slice(out, func(i, j int) bool { return out[i].Name < out[j].Name })
	return out, nil
})

// BuiltinPlugins returns the plugins compiled into this binary, sorted by
// name.
func BuiltinPlugins() []*Plugin {
	ps, err := builtinPlugins()
	if err != nil {
		panic(err)
	}
	return ps
}

// AvailablePlugins is every plugin a page can draw styles from: the
// built-ins and extra, sorted by name. One plugin listed twice is one
// plugin; two different plugins with one name are an error, since a
// qualified style name could not tell them apart.
func AvailablePlugins(extra []*Plugin) ([]*Plugin, error) {
	byName := map[string]*Plugin{}
	var out []*Plugin
	for _, p := range append(append([]*Plugin{}, BuiltinPlugins()...), extra...) {
		if q, ok := byName[p.Name]; ok {
			if q.key == p.key {
				continue
			}
			return nil, fmt.Errorf("plugins %s and %s are both named %q; rename one", where(q), where(p), p.Name)
		}
		byName[p.Name] = p
		out = append(out, p)
	}
	sort.Slice(out, func(i, j int) bool { return out[i].Name < out[j].Name })
	return out, nil
}

// where names a plugin's location for a message.
func where(p *Plugin) string {
	if p.dir == "" {
		return "built-in " + p.Name
	}
	return p.dir
}

// findPlugin returns the plugin named name in ps, or nil.
func findPlugin(ps []*Plugin, name string) *Plugin {
	for _, p := range ps {
		if p.Name == name {
			return p
		}
	}
	return nil
}
```

```go
package md2html

import (
	"fmt"
	"strings"
	"sync"
)

// sheetEntry is one assembled stylesheet, built once per resolved style
// list however many pages select it.
type sheetEntry struct {
	once sync.Once
	css  string
	err  error
}

// selected is one resolved style and the plugin it came from.
type selected struct {
	plugin *Plugin
	style  *Style
}

func (s selected) qualified() string { return s.plugin.Name + "/" + s.style.Name }

// Stylesheet returns the stylesheet for a page that selects names, stacked
// in order: the default stylesheet, unless the first style starts from
// nothing, and then each style's CSS with its assets inlined. Names resolve
// against the built-in plugins plus plugins. No names means the default.
//
// A style other than the first may not start from nothing: it would
// discard styles the same list asked to keep. Selecting one style twice
// keeps the first and warns, since the second adds nothing but bytes.
func (c *PluginCache) Stylesheet(names []string, plugins []*Plugin, warn func(string)) (string, error) {
	if len(names) == 0 {
		return defaultCSS, nil
	}
	avail, err := AvailablePlugins(plugins)
	if err != nil {
		return "", err
	}
	var picks []selected
	seen := map[string]bool{}
	for _, n := range names {
		s, err := resolveStyle(n, avail)
		if err != nil {
			return "", err
		}
		if seen[s.plugin.key+"/"+s.style.Name] {
			if warn != nil {
				warn(fmt.Sprintf("style %s is selected twice; using it once", s.qualified()))
			}
			continue
		}
		seen[s.plugin.key+"/"+s.style.Name] = true
		if len(picks) > 0 && s.style.BaseNone {
			return "", fmt.Errorf("style %s starts from nothing (base: none), so it can only come first", s.qualified())
		}
		picks = append(picks, s)
	}

	keys := make([]string, len(picks))
	for i, s := range picks {
		keys[i] = s.plugin.key + "/" + s.style.Name
	}
	key := strings.Join(keys, "\x00")
	c.mu.Lock()
	e, ok := c.sheets[key]
	if !ok {
		e = &sheetEntry{}
		c.sheets[key] = e
	}
	c.mu.Unlock()
	e.once.Do(func() { e.css, e.err = assemble(picks) })
	return e.css, e.err
}

// assemble concatenates the default stylesheet, unless the first pick
// starts from nothing, and each pick's CSS files in order, one newline
// between parts. A lone base-none pick is its CSS exactly, so selecting
// the default style reproduces defaultCSS byte for byte.
func assemble(picks []selected) (string, error) {
	var parts []string
	if !picks[0].style.BaseNone {
		parts = append(parts, defaultCSS)
	}
	for _, s := range picks {
		for _, f := range s.style.css {
			b, err := s.plugin.readFile(f)
			if err != nil {
				return "", fmt.Errorf("style %s: %w", s.qualified(), err)
			}
			css, err := inlineAssets(string(b), f, s.plugin.readFile)
			if err != nil {
				return "", fmt.Errorf("plugin %s: %w", s.plugin.Name, err)
			}
			parts = append(parts, css)
		}
	}
	return strings.Join(parts, "\n"), nil
}

// resolveStyle finds the style a name selects. A qualified name picks from
// one plugin; a bare one must match exactly one available style, and the
// error for an ambiguous one lists the qualified names to choose between.
func resolveStyle(name string, avail []*Plugin) (selected, error) {
	if pl, st, ok := strings.Cut(name, "/"); ok {
		p := findPlugin(avail, pl)
		if p == nil {
			return selected{}, fmt.Errorf("no plugin named %q; load it with --plugin or front matter plugins:", pl)
		}
		s, ok := p.Styles[st]
		if !ok {
			return selected{}, fmt.Errorf("plugin %s has no style %q; it has %s", pl, st, strings.Join(p.StyleNames(), ", "))
		}
		return selected{p, s}, nil
	}
	var matches []selected
	var all []string
	for _, p := range avail {
		for _, n := range p.StyleNames() {
			all = append(all, p.Name+"/"+n)
			if n == name {
				matches = append(matches, selected{p, p.Styles[n]})
			}
		}
	}
	switch len(matches) {
	case 1:
		return matches[0], nil
	case 0:
		return selected{}, fmt.Errorf("no style named %q; available: %s", name, strings.Join(all, ", "))
	}
	var q []string
	for _, m := range matches {
		q = append(q, m.qualified())
	}
	return selected{}, fmt.Errorf("style %q is ambiguous; name one of: %s", name, strings.Join(q, ", "))
}

// splitList reads a comma-separated list, as --style, --plugin and their
// front matter keys take, dropping blank entries.
func splitList(s string) []string {
	var out []string
	for _, part := range strings.Split(s, ",") {
		if p := strings.TrimSpace(part); p != "" {
			out = append(out, p)
		}
	}
	return out
}
```

```go
// maxStylesheet is the size past which a page's stylesheet is warned
// about: every page carries its own copy, and an Artifact is capped at
// 16 MB, fonts and all.
const maxStylesheet = 1 << 20

// pageCSS chooses one page's stylesheet: its front matter "style:" if it
// has one, otherwise the run's CSS or Styles, otherwise the default.
//
// A front matter choice that fails is warned about and the page falls back
// to the run's whole style list, not to the list minus the bad entry: a
// page that loses one of three stacked styles renders as a look nobody
// chose. The run's own choice failing is an error, since a caller that
// asked for a style and silently got another would ship the wrong look.
func pageCSS(opt Options, meta map[string]string) (string, error) {
	warn := func(s string) {
		if opt.Warn != nil {
			opt.Warn(s)
		}
	}
	if opt.CSS != "" && len(opt.Styles) > 0 {
		return "", errors.New("Options.CSS and Styles are both set; choose one")
	}
	cache := opt.PluginCache
	if cache == nil {
		cache = NewPluginCache()
	}
	run := func() (string, error) {
		if opt.CSS != "" {
			return opt.CSS, nil
		}
		if len(opt.Styles) == 0 {
			return defaultCSS, nil
		}
		ps, err := cache.LoadAll(opt.Plugins, "", nil)
		if err != nil {
			return "", err
		}
		return cache.Stylesheet(opt.Styles, ps, nil)
	}

	names := splitList(meta["style"])
	pageDirs := splitList(meta["plugins"])
	var css string
	var err error
	switch {
	case len(names) == 0:
		// The page's plugins only widen what its own style: can name; the
		// run's list resolves against the run's plugins, so loading one here
		// can never make the run's bare name ambiguous on this page.
		if len(pageDirs) > 0 {
			warn("front matter plugins has no effect without style; ignoring it")
		}
		css, err = run()
	default:
		css, err = frontMatterCSS(cache, opt, names, pageDirs, warn)
		if err != nil {
			warn(err.Error() + "; using the run's style")
			css, err = run()
		}
	}
	if err != nil {
		return "", err
	}
	if len(css) > maxStylesheet {
		warn(fmt.Sprintf("stylesheet is %d KB, over 1 MB; every page carries it", len(css)/1024))
	}
	return css, nil
}

// frontMatterCSS assembles a page's own style list from the run's plugins
// and the page's, the page's resolved against its own directory. The error
// says which key was at fault, for the warning pageCSS raises.
func frontMatterCSS(cache *PluginCache, opt Options, names, pageDirs []string, warn func(string)) (string, error) {
	ps, err := cache.LoadAll(opt.Plugins, "", nil)
	if err != nil {
		return "", fmt.Errorf("front matter style: %w", err)
	}
	baseDir := ""
	if opt.SourcePath != "" {
		baseDir = filepath.Dir(opt.SourcePath)
	}
	own, err := cache.LoadAll(pageDirs, baseDir, warn)
	if err != nil {
		return "", fmt.Errorf("front matter plugins: %w", err)
	}
	css, err := cache.Stylesheet(names, append(ps, own...), warn)
	if err != nil {
		return "", fmt.Errorf("front matter style: %w", err)
	}
	return css, nil
}
```

```go
// listAvailableStyles prints every style a run could select, grouped by
// plugin: the plugin's name and description, then each style's qualified
// name and description, indented beneath it.
func listAvailableStyles(dirs []string, stdout, stderr io.Writer) int {
	warn := func(m string) { fmt.Fprintf(stderr, "md2html: %s\n", m) }
	loaded, err := md2html.NewPluginCache().LoadAll(dirs, "", warn)
	if err != nil {
		fmt.Fprintf(stderr, "md2html: %v\n", err)
		return 2
	}
	all, err := md2html.AvailablePlugins(loaded)
	if err != nil {
		fmt.Fprintf(stderr, "md2html: %v\n", err)
		return 2
	}
	for _, p := range all {
		if p.Description != "" {
			fmt.Fprintf(stdout, "%s: %s\n", p.Name, p.Description)
		} else {
			fmt.Fprintf(stdout, "%s\n", p.Name)
		}
		for _, n := range p.StyleNames() {
			fmt.Fprintf(stdout, "  %s/%s  %s\n", p.Name, n, p.Styles[n].Description)
		}
	}

}
```

```go
// themeBlock returns the custom properties one block defines, by the
// block's exact selector, or nil if the CSS has no such block.
func themeBlock(css, selector string) map[string]bool {
	i := strings.Index(css, selector+" {")
	if i < 0 {
		return nil
	}
	body := css[i+len(selector)+2:]
	body = body[:strings.Index(body, "}")]
	got := map[string]bool{}
	for _, m := range regexp.MustCompile(`(--[a-z0-9-]+)\s*:`).FindAllStringSubmatch(body, -1) {
		got[m[1]] = true
	}
	return got
}
```

````markdown
## Styles

A page's look comes from styles. With none chosen it gets the default.

```text
claude-artifact: Looks from pages Claude publishes as Artifacts
  claude-artifact/claude-artifact  The rules every Artifact follows, …

  default/default  Warm neutrals, system fonts, both themes
```

### Choosing styles

`--style claude-artifact` styles every page in the run. `style:
claude-artifact` in a page's front matter styles that page and replaces
the run's choice for it, the way `lang:` replaces `--lang`. `style:
default` gives one page the plain default inside a run that chose
something else.

Both take a comma-separated list, stacked in order: `style:
claude-artifact, wide-tables` puts `wide-tables` on top of
`claude-artifact`, and later styles win where they overlap. Name a style
alone, or as `plugin/style` when two plugins have a style of that name;
md2html says when you need to.

`--css mine.css` still replaces the stylesheet outright. It cannot be
combined with `--style`, and a page's `style:` overrides it.

### Loading a plugin

Styles come from plugins. The built-in ones are always loaded. Load
another with `--plugin path/to/it` for a whole run, or with `plugins:
./_style` in a page's front matter, relative to the page. Both take a
comma-separated list. A page's `plugins:` only matters with its own
`style:`.

### Writing a plugin

A plugin is a directory holding an `md2html-plugin.json` manifest and the
files it names. This one provides a style called `house` that changes the
accent colour and the text column's width:

```json
{
  "format": 1,
  "name": "acme",
  "description": "Acme's documentation look",
  "styles": {
    "house": {
      "description": "Acme blue, a wider column",
      "css": ["house.css"]
    }
  }
}
```

```css
:root { --accent: #1f5fa8; --measure: 72ch; }
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) { --accent: #8ab4f0; }
}
:root[data-theme="dark"] { --accent: #8ab4f0; }
:root[data-theme="light"] { --accent: #1f5fa8; }
```

| Key | Meaning |
|---|---|
| `format` | Always `1`. |
| `name` | The plugin's name: lowercase letters, digits and hyphens. |
| `description` | One line for `--list-styles`. |
| `styles` | Each style by name: its `description`, its `css` files in order, and `base`. |

A style is added on top of the default stylesheet, so it only needs to say
what differs. `"base": "none"` starts from nothing instead, and is only
allowed for the first style a page lists.

Fonts and images the CSS names with `url(fonts/x.woff2)` are copied into
every page as `data:` URIs, so the page stays one file that loads nothing.
For the same reason a plugin cannot use `@import`, a web address, or a
file outside its own directory: each is an error naming the file.

### What a style can change

The default stylesheet draws every colour from these custom properties.
Redefining them is the simplest way to restyle a page:

| Property | Used for |
|---|---|
| `--bg`, `--fg` | Page background and text |
| `--muted` | Secondary text: subtitle, date, captions |
| `--accent` | Links, callout rules, the contents list |
| `--rule` | Borders and table lines |
| `--code-bg` | Code, callout and card backgrounds |
| `--warn`, `--ok` | Warning callouts, and the status badges |
| `--measure` | The text column's width |

Set each colour four times: on `:root`, in the
`@media (prefers-color-scheme: dark)` block for
`:root:not([data-theme="light"])`, on `:root[data-theme="dark"]`, and on
`:root[data-theme="light"]`. The example above shows the shape.

Classes you can style, beyond plain elements: `callout`, `card`, `group`,
`stats`, `defs`, `details.container`, `chip` and `chip-*`, `xref`,
`nav.toc`, `subtitle`, `docdate`, `code-figure`, `fig` and `fig-*`,
`table-scroll`, `anchor`, `source-tools`. A class you add to your own
Markdown is inert until a style names it.

### What a plugin cannot do yet

A plugin cannot add scripts, change the page's HTML (no header bar, no
footer), or add new containers or badges. If a page needs one of those,
write it in the Markdown as raw HTML, or say it isn't possible yet.

### Checking a style

Run `md2html --plugin ./_style --list-styles` to check a plugin loads; a
broken one exits with the reason. Then build a page and look at it at 400px
wide and in both themes. A front matter `style:` that fails warns and the
page falls back to the run's style, so read the warnings.
````
